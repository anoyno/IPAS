L1 正則化（Lasso）
Least Absolute Shrinkage and Selection Operator
在損失函數加入權重的絕對值之和。效果是讓不重要的權重直接歸零，有自動特徵選擇的效果。
Loss = Loss₀ + λ Σ|wᵢ|
適合特徵很多但只有少數真正有用的情境（稀疏模型）。
🔪 國中生版本
想像你有一個特別任性的老師，他規定：「如果你的分數中有某科貢獻不大，我就直接把你在那科的分數砍掉，變成 0。」所以最後你會只保留真正有用的科目，其他直接廢掉。這就是 L1 砍到歸零的概念。
參數懲罰特徵選擇稀疏模型
λ₂
L2 正則化（Ridge）
Weight Decay / Tikhonov Regularization
在損失函數加入權重的平方和。效果是讓所有權重趨近於小值但不會歸零，讓模型整體更平滑。
Loss = Loss₀ + λ Σwᵢ²
深度學習中常稱為 Weight Decay，是最常用的正則化方式。
📉 國中生版本
想像你是個貪心的商人，喜歡把錢都花在某件事上（某個權重特別大）。但有個稅務官說：「權重越大我就越課重稅」，所以你被迫把錢分散到各種事業上，讓每個都稍微縮小一點。這樣雖然沒有人失業，但每個人都被迫變小。
參數懲罰深度學習最常用
⚡
Elastic Net
L1 + L2 Combined
L1 與 L2 的混合版本，用超參數 α 控制兩者比例。兼具 L1 的稀疏性與 L2 的穩定性。
Loss = Loss₀ + λ[α Σ|wᵢ| + (1-α) Σwᵢ²]
特徵之間高度相關時比單獨 L1 更穩定。
⚖️ 國中生版本
L1 說：「廢人砍掉」，L2 說：「每人都縮水」。Elastic Net 就是兩方都聽一點，各退一步。這樣既能刪除廢人，也能讓倖存者不會太弱。最靈活的做法。
參數懲罰高相關特徵
⊘
Dropout
Random Neuron Deactivation
訓練時隨機關閉一定比例的神經元，防止神經元之間過度共同依賴。預測時全部神經元開啟。
p = 0.5（隱藏層） p = 0.1~0.2（輸入層）
相當於同時訓練多個子網路並取集成平均。
👥 國中生版本
想像一個班級在做小組作業，有個調皮的老師規定：「每堂課我隨機請假 50% 的學生」。學生們被迫不能依賴某個聰明的人，每個人都得獨立思考。這樣訓練出來的隊伍，即使某人請假也能應付。
架構設計深度學習預測時開啟
∑
Batch Normalization
Internal Covariate Shift Reduction
每一層的輸出在 mini-batch 內做標準化，穩定訓練過程。雖然主要目的是加速訓練，但也有輕微的正則化效果。
x̂ = (x − μ_B) / √(σ²_B + ε)
使用 BN 後通常可以降低 Dropout 的使用需求。
📏 國中生版本
每一層出來的資料都「亂七八糟」（分布不穩定），BN 就是在每一層都裝一個「整隊機器」，把資料整理整齊後再往下傳。這樣下一層就能安心工作，訓練變快也更穩定。
訓練策略加速訓練間接正則化
⏹
Early Stopping
Training Termination by Validation Loss
監控驗證集的損失，當驗證損失不再下降時就提早停止訓練，避免在訓練集上過度擬合。
if val_loss 連續 patience 輪沒改善 → 停止
最簡單有效的方法之一，幾乎沒有額外計算成本。
🛑 國中生版本
模型就像學生讀書，一開始進度快（訓練集分數高）。但讀到某一點後，新知識幫助不大了，反而容易死背（過度擬合）。Early Stopping 就是說：「不要貪心，見好就收，看考卷（驗證集）不進步就停。」
訓練策略所有模型零成本
🔀
資料增強
Data Augmentation
透過對訓練資料做隨機變換（翻轉、裁剪、旋轉、加噪等）人工擴充資料量，讓模型學習更多樣的輸入分佈。
影像：flip / crop / rotate / color jitter
文字：synonym replace / back-translation
資料量不足時效果最明顯。
🎭 國中生版本
你只有 100 張貓咪照片，但想訓練識別貓的 AI。Data Augmentation 就像拿同一隻貓的照片，翻轉它、模糊它、改變角度、改變光線，變成 1000 張「不同的貓」。這樣 AI 見過更多變化，不會只死背原本 100 張。
資料增強影像 / NLP資料不足
≈
Label Smoothing
Soft Target Regularization
把 one-hot 標籤的 1 換成 1−ε，0 換成 ε/(K−1)，讓模型不要對預測結果過度自信，提升泛化能力。
y_smooth = (1 − ε) · y_hard + ε / K
常用於分類任務，ε 通常設 0.1。
😌 國中生版本
老師說「這題答案是 A」，模型就100% 相信是 A，完全不考慮 B、C、D。但實務上，也許 B 有 5% 機率是對的。Label Smoothing 就是教模型：「別太確定，留點謙遜，其他選項也有小機率是對的。」
訓練策略分類任務ε ≈ 0.1
✕
Mixup
Convex Combination Augmentation
隨機取兩筆訓練資料做線性插值，輸入和標籤都混合，讓模型學習更平滑的決策邊界。
x̃ = λxᵢ + (1−λ)xⱼ
ỹ = λyᵢ + (1−λ)yⱼ
在影像分類和 NLP 都有顯著提升效果。
🍹 國中生版本
你有一張「貓」的照片和一張「狗」的照片，Mixup 就是把它們50% 混起來，變成一張既像貓又像狗的混合體，標籤也是 50% 貓 + 50% 狗。模型學習這種「模糊地帶」，決策邊界就變得平滑，不容易過度擬合。

問題：One-hot 標籤

模型被迫追求無限自信 → 死背訓練資料

Min-Max 正規化
Min-Max Normalization
把所有值壓縮到 [0, 1] 的範圍內（也可以指定其他區間如 [−1, 1]）。保留原始分佈形狀，但對離群值很敏感。
x' = (x − x_min) / (x_max − x_min)
資料沒有特別的分佈假設時適用，常用於影像像素值（0~255 → 0~1）。
📊 國中生版本
想像班上學生的身高從 140cm 到 200cm。Min-Max 就是把最矮的變成 0，最高的變成 1，其他人線性插在中間。缺點：如果突然來一個 220cm 的外星人，整個排名就亂掉。
縮放類影像處理離群值敏感
σ
Z-score 標準化
Standardization / Z-score Normalization
轉換為平均值 0、標準差 1 的分佈。不改變分佈形狀，對離群值比 Min-Max 更穩健。
x' = (x − μ) / σ
假設資料近似常態分佈時效果最好。線性模型、SVM、PCA 的標準前處理步驟。
📈 國中生版本
班上考試成績，平均 70 分、標準差 10 分。Z-score 把分數轉成：你的成績多少個「標準差」遠離平均。80 分的人就是 +1（比平均高 1 個標準差），60 分的人就是 -1。這樣可以比較不同科目的成績，是最常用的標準化方法。
分佈轉換最常用線性模型
⚖
Robust Scaling
Median & IQR Based Scaling
用中位數（median）和四分位距（IQR）代替平均數和標準差來縮放，極端值影響較小。
x' = (x − median) / IQR
IQR = Q3 − Q1
資料中有明顯離群值、又不想刪掉時的首選。
🛡️ 國中生版本
Z-score 怕離群值（如一個考 150 分的天才會毀掉平均）。Robust Scaling 改用「中位數」代替平均，因為中位數是「中間那個人」，不受極端值影響。就像你要描述班級成績，說「中位數 70」比「平均 75（但有人考 0、有人考 150）」更真實。
抗離群值有離群值
㏒
Log 轉換
Log Transformation
對數值取 log，將右偏分佈（長尾分佈）壓縮成近似常態分佈。適合數值跨越多個數量級的特徵。
x' = log(x + 1) （+1 避免 log(0)）
薪資、房價、瀏覽量等呈冪律分佈的資料特別有效。
📊 國中生版本
薪資分佈很奇怪：大多數人 30 萬，但有少數 CEO 賺 3000 萬（相差 100 倍！）。直接用會失衡。Log 轉換就是把這個「1 倍、10 倍、100 倍」的關係，轉成「1、2、3」的線性關係。這樣 AI 就能處理了。
分佈轉換右偏分佈冪律資料
→₁
L2 正規化（向量）
Unit Vector / L2 Normalization
將每個樣本的特徵向量縮放為單位長度（長度 = 1），保留方向、忽略大小。
x' = x / ‖x‖₂ = x / √(Σxᵢ²)
文字特徵（TF-IDF）、餘弦相似度計算前的標準步驟。注意跟 L2 正則化不同！
🧭 國中生版本
你和朋友都喜歡「籃球、足球、電玩」，但你花的時間不同（籃球 100 小時、足球 50、電玩 30），朋友花更多（籃球 1000、足球 500、電玩 300）。L2 正規化說：「忽略你們花的總時間，只看比例方向是否一樣」。這樣可以比較喜好的相似度。
⚠️ 容易混淆：L2 同時出現在兩個地方
L2 正則化（Regularization）
作用對象：模型權重 w
發生時機：訓練時（加在 Loss 裡）
目的：防止過擬合
公式：Loss += λ × Σw²
L2 正規化（Normalization）← 本頁
作用對象：資料向量 x
發生時機：預處理時（改資料）
目的：統一向量長度
公式：x' = x / ‖x‖₂
記憶：正則化 → 規則約束模型；正規化 → 規格統一資料
向量縮放NLP相似度計算
∥
Layer Normalization
Per-Sample Feature Normalization
對每個樣本在特徵維度上做標準化（Batch Norm 是在 batch 維度上做）。不受 batch size 影響，適合序列模型。
x' = (x − μ_sample) / σ_sample
Transformer、RNN 的標準配備，batch size 小或變長序列時比 Batch Norm 更穩定。
👤 國中生版本
Batch Norm 是「比較整個班級的同學」。但序列模型（讀句子）不在乎其他句子怎樣，只在乎自己的特徵標準化。Layer Norm 就是「每個人獨立調整自己」，不受班級同學影響。Transformer 用 Layer Norm，因為句子長度差異大。

Power Transform
Box-Cox / Yeo-Johnson
用數學方式找出最佳的冪次轉換，讓資料分佈盡量接近常態分佈。Box-Cox 只能處理正數，Yeo-Johnson 可以處理負數。
Box-Cox: x' = (xλ − 1) / λ (λ ≠ 0)
Yeo-Johnson: 適用正負值
比 Log 轉換更彈性，自動學習最佳 λ。
🔬 國中生版本
Log 轉換是「我知道怎麼轉」。Power Transform 是「讓 AI 自己試試看，用 x^0.5、x^0.3、x^2 等各種冪次，找到讓分佈最「正常」的那個」。是更聰明的自動轉換方式，但計算成本較高。

🏫 監督式學習
Supervised Learning
每筆訓練資料都有正確答案（標籤），模型從「題目 + 解答」裡學規律。
輸入：貓的照片

→ 模型學「這樣的圖 = 貓」
比喻：有解答本的練習題
🔍 非監督式學習
Unsupervised Learning
資料沒有標籤，模型自己找資料裡的結構、規律、群組。
輸入：一堆動物照片
標籤：沒有
→ 模型自己分成幾群
比喻：沒解答，自己找規律

// 監督式學習 — 常見方法
📏
線性回歸
Linear Regression
用一條直線（或超平面）擬合資料，預測連續數值。最簡單的監督式模型，可解釋性高。
ŷ = w₀ + w₁x₁ + w₂x₂ + ...
例：根據房子坪數預測售價。
📊 國中生版本
想像你有很多「房子坪數 vs 售價」的資料點。線性回歸就是找一條最佳直線，讓所有點都盡量貼著這條線。然後用這條線預測新房子的價格。簡單直白，但只適合「大致成直線」的關係。
回歸線性模型高可解釋性
🚦
羅吉斯回歸
Logistic Regression
名字叫「回歸」但實際做分類，輸出機率值（0~1）。常作為深度學習最後一層的基礎。
P(y=1) = σ(wᵀx) = 1 / (1 + e⁻ᶻ)
例：預測這封信是不是垃圾郵件。
🎲 國中生版本
線性回歸預測「房價多少」（數字）。羅吉斯回歸做「是還是不是」（0 或 1），但輸出的是機率（0.7 表示 70% 可能是垃圾郵件）。就是在直線輸出套上一個 S 形函數，把數值壓到 0~1。
分類線性模型輸出機率
🌳
決策樹
Decision Tree
用一系列「是/否」問題把資料分開，像流程圖。直觀易懂，但容易過擬合，通常搭配整合方法使用。
分裂準則：Gini / Entropy / MSE
例：根據症狀判斷是哪種病。
🌳 國中生版本
像玩「猜猜我是誰」：每次問一個是非題縮小範圍。「有4條腿嗎？」→「會飛嗎？」→「答案是鳥！」。決策樹就是自動找出最好的問題順序，每次問完把資料分成兩堆，一直問到答案出來。
分類 / 回歸高可解釋性易過擬合
🌲
隨機森林
Random Forest
訓練很多棵決策樹，最後投票取結果（Bagging）。比單棵樹穩定很多，不容易過擬合。
f(x) = majority_vote(tree₁, tree₂, ..., treeₙ)
實務上最常用的入門強力模型之一。
🌲 國中生版本
一棵決策樹容易「太死記」（過擬合）。隨機森林的做法是種很多棵樹，每棵看不同的資料子集，最後讓全部的樹投票，誰票多聽誰的。就像考試不靠一個同學，而是問全班再取平均。
分類 / 回歸集成方法穩健
⚡
梯度提升樹 — GBDT vs XGBoost
Gradient Boosting Decision Tree → eXtreme Gradient Boosting
🌳 核心概念（兩者共同）
每棵新樹專門修正前面樹的殘差（錯誤），一棵接一棵疊加。
F(x) = F₀(x) + η·h₁(x) + η·h₂(x) + ...　η = 學習率
⚡ XGBoost 相較 GBDT 的六大改進
① 二階梯度（泰勒展開）
GBDT 只用一階梯度（坡度方向），XGBoost 同時用二階梯度（坡度變化率），更精確控制每步走多大。
GBDT：知道往哪走
XGB：還知道走多大步
② 內建正則化
損失函數直接加入 L1 + L2，懲罰葉節點數量和權重，防止樹長得太複雜。
Obj += γT + ½λ‖w‖²
T=葉節點數　w=葉節點權重
③ 缺失值自動處理
GBDT 需手動填補缺失值。XGBoost 訓練時自動學習「遇到 NaN 往左還是往右分」，不需要預處理。
④ 近似分裂算法
GBDT 遍歷所有可能的分裂點（慢）。XGBoost 用分位數近似，只在 25%、50%、75% 等邊界找，速度快且精度損失小。
GBDT：遍歷百萬值
XGB：只看幾個分位數
⑤ 列採樣（特徵隨機）
每棵樹隨機選一部分特徵（像隨機森林），讓每棵樹看到不同視角，增加多樣性、減少過擬合。
⑥ 並行計算 + 快取優化
同一層節點並行計算（多核 CPU），資料預排序進快取，這也是名字裡 eXtreme（極致） 的由來。
改進點GBDTXGBoost
梯度資訊一階一階 + 二階 ✓
正則化無L1 + L2 內建 ✓
缺失值需手動處理自動學習 ✓
特徵採樣全部特徵隨機子集 ✓
分裂算法遍歷所有值（慢）分位數近似（快）✓
計算速度序列（慢）並行（快）✓
💡 一句話：XGBoost = GBDT + 更聰明的數學（二階梯度） + 正則化（防過擬合） + 工程優化（速度快）
💡 記憶要點：XGBoost = GBDT + L1/L2 + 缺失值預設 + 並行特徵分裂

🚀
LightGBM
Light Gradient Boosting Machine
Microsoft 開發的梯度提升框架，目標是在保留 XGBoost 準確度的前提下大幅提升速度。
核心差異：Leaf-wise 生長 vs XGBoost 的 Level-wise 生長
XGBoost — Level-wise（逐層生長）
第1層：分裂所有節點
第2層：再分裂所有節點
→ 每層平均生長，比較穩定
→ 但很多低增益的節點也被分裂
LightGBM — Leaf-wise（葉子優先）
每次找 loss 下降最多的葉子
→ 只分裂最值得分裂的節點
→ 同樣棵樹能學到更多
→ 速度快 3~10 倍
LightGBM 的三大技術優勢
直方圖算法：特徵值分桶，記憶體用量大幅減少
GOSS（梯度採樣）：只用梯度大的樣本，減少計算量
EFB（特徵捆綁）：稀疏特徵合併，降低特徵維度
🚀 國中生版本
XGBoost 每層把所有節點都分一遍，不管重不重要。LightGBM 每次只找「最值得分裂的那個葉子」，跳過沒意義的節點。就像考試複習，XGBoost 每章從頭讀到尾，LightGBM 直接找分數最差的章節重點攻。效率高很多，大資料集時差距更明顯。
XGBoostLightGBM
生長策略Level-wise（逐層）Leaf-wise（葉子優先）
訓練速度中等快 3~10 倍
記憶體較高較低（直方圖）
大資料集可以更好
小資料集更穩定Leaf-wise 容易過擬合
類別特徵需手動編碼原生支援
💡 記憶要點：LightGBM = XGBoost 的速度升級版。大資料 / 特徵多 → 優先選 LightGBM；小資料 / 穩定性優先 → XGBoost 也很好。

支援向量機
SVM — Support Vector Machine
找到讓兩類資料間距最大的邊界（超平面）。用 kernel trick 可以處理非線性分類。
最大化間距：2 / ‖w‖
高維度、小資料集時效果不錯。
📐 國中生版本
把兩群點畫在紙上，SVM 要找一條線把它們分開，而且要讓兩邊離這條線的距離盡量最寬（留最寬的走廊）。讓邊界穩固，新資料不容易分錯。當資料無法用直線分時，用 kernel trick「升維」到可以分的空間。

K 近鄰法
KNN — K-Nearest Neighbors
找最近的 K 個鄰居，用多數決決定類別。沒有「訓練」過程，預測時才計算距離。
ŷ = mode(y₁, y₂, ..., yₖ) — K個最近鄰
直覺簡單，但資料量大時預測慢。
👥 國中生版本
「你跟誰最像，你就跟他一樣」。KNN 不用事先訓練，預測時直接找 K 個最近的鄰居，看他們大多數是什麼類別，就猜這個新點也是那個類別。就像你轉學到新學校，看最近坐的幾個同學喜歡什麼，就猜你也喜歡什麼。

Neural Network / Deep Learning

樸素貝葉斯
Naive Bayes
基於貝葉斯定理，假設所有特徵彼此獨立（雖然現實中常不成立）。速度極快，資料少時也能用。
P(y|x) ∝ P(y) × ΠP(xᵢ|y)

// 不平衡資料處理（Class Imbalance）
💡 什麼是類別不平衡？
訓練資料中各類別數量差異極大。例如詐騙偵測：99% 正常交易、1% 詐騙。模型直接預測全部為「正常」也有 99% 準確率，但完全沒有學到詐騙的特徵。需要特殊處理才能讓模型真正學會少數類別。
🧬
SMOTE
Synthetic Minority Over-sampling Technique
在少數類別樣本之間「插值」生成新的合成樣本，而非單純複製，讓少數類別的樣本數量增加到與多數類別相近。
⚙️ 運作步驟
① 選一個少數類別樣本 x從所有少數類別的點中隨機選一個
② 找 K 個最近鄰在少數類別裡找最近的 K 個點（通常 K=5）
③ 隨機選一個鄰居 x'從 K 個鄰居中隨機挑一個
④ 在兩點之間插值x_new = x + λ × (x' − x)，λ ∈ [0, 1] 隨機
原始少數樣本：A=(2,3)　B=(4,7)
λ=0.6 → 合成樣本 = (2,3) + 0.6×(2,4) = (3.2, 5.4)　← 新樣本落在兩點連線上
❌ 單純複製（Over-sampling）
把少數類別樣本直接複製貼上。模型反覆看同樣的點，容易過擬合這幾個點，決策邊界不夠通用。
✓ SMOTE（合成插值）
在已有樣本之間生成全新的合成點，讓少數類別的分布更完整，決策邊界更平滑、泛化更好。
🧬 國中生版本
假設詐騙交易只有 100 筆，正常交易有 10000 筆。SMOTE 不是把這 100 筆複製 100 次，而是找兩筆相似的詐騙交易，在它們「中間」造出一筆新的假詐騙交易（特徵值介於兩者之間）。就像在地圖上兩個城市之間「憑空建一座新城市」，讓少數類別的地盤更豐富，模型更容易學到規律。
SMOTE 變體
Borderline-SMOTE：只在決策邊界附近的樣本間插值，更有針對性
ADASYN：難以分類的少數樣本附近生成更多合成樣本
SMOTE + Tomek Links：過採樣後再清除邊界上的多數類別噪點
SMOTE + ENN：用 Edited Nearest Neighbour 清理生成後的噪音
⚠️ 為什麼不適合高維稀疏資料？
高維 = 特徵數量極多（如 TF-IDF 文本有 10 萬個維度）；稀疏 = 大部分特徵值都是 0（一篇文章只用到幾百個詞，其餘欄位全是 0）。
在高維空間裡，每個點和其他點的距離都差不多遠（維度詛咒），「最近鄰」的概念失去意義，SMOTE 插值出的合成樣本可能完全不真實。
過採樣不平衡資料詐騙偵測 / 醫療診斷不適合高維稀疏資料
✂️
Under-sampling（欠採樣）
Random Under-sampling / Tomek Links
從多數類別中隨機刪除一些樣本，讓兩類數量接近。
多數類別：10000 筆 → 隨機刪到 1000 筆
少數類別：1000 筆 → 維持不動
→ 比例從 10:1 變為 1:1
✂️ 國中生版本
班上 100 個正常學生、5 個特殊學生，老師只看 5 個正常學生的資料來學。簡單快速，但會丟失大量多數類別的資訊，資料本來就不多時不適合用。
簡單快速丟失資訊
⚖️
Class Weights（類別權重）
Cost-sensitive Learning
不改變資料，而是在損失函數裡讓少數類別的錯誤罰得更重。
weight_minority = N_total / (2 × N_minority)
loss = −[w₁·y·log(p) + w₀·(1−y)·log(1−p)]
sklearn: class_weight='balanced'
⚖️ 國中生版本
不增刪資料，直接告訴模型：「你如果把詐騙猜成正常，罰你 10 分；把正常猜成詐騙只罰 1 分」。最簡單、不需要生成假資料，是實務上的第一選擇。
最簡單實務首選不需生成資料
方法原理優點缺點適合情境
SMOTE合成少數類別樣本增加多樣性、不過擬合高維稀疏資料效果差資料量中等、結構化資料
Under-sampling刪除多數類別樣本快速、降低計算量丟失有用資訊資料量非常大
Class Weights調整損失函數權重最簡單、不改資料無法處理極端不平衡輕微不平衡的第一選擇
// 線性 / 二次判別分析（LDA & QDA）
💡 共同前提：高斯判別分析
兩者都假設每個類別的資料服從多變量高斯分布，利用貝葉斯定理計算「這筆資料屬於哪個類別的機率最高」。差別在於各類別的協方差矩陣是否共用。
—
LDA（線性判別分析）
Linear Discriminant Analysis
假設所有類別共用同一個協方差矩陣 Σ，決策邊界是線性的（超平面）。
假設：P(x|y=k) = N(μₖ, Σ)　← 所有類別共用 Σ
決策邊界：線性（超平面）
需估參數：d(d+1)/2 個（整體共用一個 Σ）
📐 協方差矩陣是什麼？
記錄每兩個特徵之間「一起變動的程度」的矩陣（見數學工具頁）。d 個特徵 → d×d 的矩陣，需估計 d(d+1)/2 個獨立參數。
— 國中生版本
想像貓和狗的身高體重分布，LDA 認為「貓的體型變化規律」和「狗的體型變化規律」是一樣的，只是中心點不同。所以用一條直線就能把兩群分開。參數少、估計穩，適合高維少樣本。
優點：共用 Σ 讓樣本有效利用，高維少樣本仍穩定
缺點：若各類別形狀真的不同，線性邊界會欠擬合
也用於：監督式降維——找出最能區分類別的投影方向
分類高維少樣本穩健線性邊界
∪
QDA（二次判別分析）
Quadratic Discriminant Analysis
每個類別各自擁有自己的協方差矩陣 Σₖ，決策邊界是二次曲線，更彈性。
假設：P(x|y=k) = N(μₖ, Σₖ)　← 每類別各自的 Σₖ
決策邊界：二次曲線（橢圓、拋物線等）
需估參數：K × d(d+1)/2 個（每類別各估一個 Σₖ）
⚠️ 高維少樣本的危險
d=200 維，每類別需估：200×201/2 = 20,100 個參數
但每類別只有 30 筆樣本 → 樣本數 ≪ 參數數
→ 協方差矩陣估計不可靠、可能奇異（無法求逆）→ 嚴重過擬合
∪ 國中生版本
QDA 認為「貓的體型變化規律」和「狗的體型變化規律」是不同的，各自估各自的。邊界可以是橢圓形、曲線，更貼合真實分布。但要估的參數量暴增——資料夠多才能用，資料少就過擬合。
優點：邊界更彈性，各類別形狀不同時效果好
缺點：樣本少時估計不穩定，高維時幾乎不可用
適用：各類別分布形狀明顯不同，且樣本充足（n ≫ d）
分類高維少樣本易過擬合二次邊界
LDAQDA
協方差矩陣所有類別共用同一個 Σ每個類別各自的 Σₖ
決策邊界線性（超平面）二次曲線（橢圓等）
需估參數量d(d+1)/2（少）K × d(d+1)/2（多）
高維少樣本✓ 穩健✗ 容易過擬合
彈性較低（線性限制）較高（曲線邊界）
適合情境維度高、樣本少樣本充足（n ≫ d²）
💡 一句話記：彈性大不代表好——沒有足夠資料支撐的彈性只是過擬合。高維少樣本優先選 LDA。

// 非監督式學習 — 常見方法
🎯
K-Means 分群
K-Means Clustering
把資料分成 K 群，每群以重心（centroid）代表，反覆更新直到穩定。需要事先指定 K 值。
最小化：Σ ‖xᵢ − μₖ‖²
例：把客戶分成幾種消費族群。
🎯 國中生版本
把 1000 個顧客分成 3 群：先隨機放 3 個「中心點」，每個顧客歸到最近的中心點，再重新算各群的平均位置作為新中心，一直重複直到中心不動。就像找「最有代表性的集合地點」。
📊 圖解步驟（K=2）
Step 0
原始資料，尚未分群
Step 1
隨機放 K=2 個初始中心（★）
Step 2
每點歸到最近的中心
Step 3
重新計算各群平均位置 → 中心移動
Step 4（收斂）
中心不再移動 → 分群完成
重複 Step 2→3 直到中心不動：① 指派（每點找最近中心）→ ② 更新（重算重心）→ ③ 檢查（中心是否移動？）
分群客群分析需指定 K
🌿
階層式分群
Hierarchical Clustering
不需要指定群數，從每個點各自一群開始，逐步合併最近的群，產生樹狀結構（dendrogram）。
距離度量：ward / complete / average
可以從樹狀圖決定要切幾群。
🌿 國中生版本
從「每個人各自一群」開始，每次把最像的兩群合併，畫成像家族族譜的樹狀圖。不需要事先決定幾群，看完樹狀圖再決定「在哪裡切斷」要幾群。更彈性，但資料量大時比較慢。
分群不需指定 K
📉
主成分分析
PCA — Principal Component Analysis
找出資料變異最大的方向，把高維資料壓縮成低維，保留最多資訊。常用於視覺化和降維前處理。
找特徵向量：X^T X → 取前 k 個
100 個特徵 → 2D 可視化。
📉 國中生版本
資料有 100 個特徵太複雜了。PCA 找到「哪個方向的變化最大」，把資料投影到那幾個方向，用 2～3 個維度就能代表原本 100 個。就像把 3D 立體物體的「最有特色的角度」投影成 2D 平面圖。
降維視覺化前處理
🗺️
t-SNE / UMAP
Non-linear Dimensionality Reduction
把高維資料非線性壓縮到 2D/3D，保留鄰近關係，主要用於視覺化。比 PCA 更能保留局部結構。
t-SNE：慢但效果好
UMAP：快且保留全域結構
深度學習特徵向量的視覺化標準工具。
🗺️ 國中生版本
把 1000 維的詞向量「攤平」到 2D 平面，讓原本相近的點在圖上也靠近。比 PCA 更能保留局部關係（同一類的字詞聚在一起）。但注意：只能看圖，不能拿來當模型的輸入特徵。
降維視覺化不適合作前處理
🤫
自編碼器（Autoencoder）
Autoencoder — AE
神經網路版的降維：先壓縮（encoder）再還原（decoder），學習資料的精華表示。
輸入 → 瓶頸層（latent） → 還原輸出
Loss = ‖輸入 − 還原‖²
異常偵測、去除雜訊、生成模型的基礎。
🤫 國中生版本
先把圖片「壓縮」成一小段摘要（瓶頸層），再從摘要「還原」回原圖。訓練目標是讓還原後的圖盡量像原圖。如果某張圖還原得很差，代表它很不正常——這就是異常偵測的原理。
💡 記憶要點：AE 異常偵測 = 重建誤差 > 閾值 → 異常；非監督。
降維異常偵測深度學習
🔮
DBSCAN
Density-Based Spatial Clustering
基於密度分群，能自動發現任意形狀的群集，並把稀疏點標記為異常值（noise）。
參數：ε（鄰域半徑）、MinPts（最少鄰居數）
不需要指定群數，但對參數敏感。
DBSCAN 三種點的角色：
🔵 核心點 (Core)
鄰域內樣本數 ≥ MinPts
🟢 邊界點 (Border)
在核心點鄰域內，但自己不夠格
⚫ 雜訊點 (Noise)
孤立無群，既無群，也不靠近核心點
分群異常偵測任意形狀
// 光譜聚類（Spectral Clustering）
💡 為什麼需要光譜聚類？
K-means 的盲點：只能分球狀群。同心圓、月牙形等非線性結構，K-means 無論怎麼切都切錯。
光譜聚類的解法：先把資料「轉換到圖的空間」，讓原本線性不可分的結構變得線性可分，再用 K-means 完成分群。
λ̃
光譜聚類三步驟
Spectral Clustering Pipeline
01
建立相似度圖
每個資料點當節點，兩點距離越近，邊的權重越大。常用 KNN 圖或 ε-neighborhood。
Wᵢⱼ = exp(−‖xᵢ−xⱼ‖²/2σ²)
02
計算拉普拉斯矩陣特徵向量
度矩陣 D（每個節點的連線總權重）減去相似度矩陣 W，得到拉普拉斯矩陣 L，再取前 k 個最小特徵值對應的特徵向量。
L = D − W → 取前 k 個特徵向量
03
新空間用 K-means 分群
特徵向量組成的新座標空間中，原本非線性可分的資料已變得線性可分，直接跑 K-means 即可正確分群。
k 個特徵向量 → K-means(k 群)
λ̃ 國中生版本
想像同心圓的資料，K-means 只會「左右切」，永遠切錯。光譜聚類的訣竅是：先把每個點和它的鄰居「連邊建圖」，然後用拉普拉斯矩陣的特徵向量把資料「翻轉」到新的座標空間——在這個新空間裡，內圈和外圈就分開了，再用 K-means 一刀切就完成了。

// 半監督式學習 — 常見方法
🏷️
Self-Training
自我訓練
先用有標籤資料訓練模型，對無標籤資料預測，把高信心的預測加入訓練集，反覆迭代。
高信心預測 → 加入標籤資料 → 重新訓練
最簡單的半監督方法，但錯誤會累積放大。
🏷️ 國中生版本
先用少量有答案的題目學習，再對大量無答案的題目「自己猜」，把猜得最有把握的加入答案庫，繼續學習。就像先記 100 個單字，再靠這 100 個猜更多詞的意思，但猜錯的知識也會被加入，可能越學越歪。
分類錯誤會累積
🔁
一致性正則化
Consistency Regularization
對同一筆無標籤資料做不同的隨機擾動，訓練模型對兩種版本給出一致的預測。
Loss = CE(有標籤) + λ·MSE(無標籤增強版)
MixMatch、FixMatch 等 SOTA 方法的核心思想。
🔁 國中生版本
把同一張圖翻轉、調亮、加雜訊，做成兩個不同版本，要求模型對兩個版本給出一樣的預測。真正學會的人，同一道題換個說法也答得出來——這個概念就是一致性正則化。

🧬
偽標籤法
Pseudo-Labeling
對無標籤資料產生「偽標籤」，視同真實標籤一起訓練。與 Self-Training 類似，但通常搭配信心閾值過濾。
if P(y|x) > threshold → 使用偽標籤
深度學習競賽常用技巧，效果顯著。
🧬 國中生版本
模型對無標籤資料猜測答案，只有「信心超過 90%」的猜測才當作真答案繼續訓練。像考試猜題：確定的才填，不確定的留白不填錯。Kaggle 比賽常用這招在測試集上再「加訓」一輪，提升分數。

// 強化學習核心算法 — Q-Learning vs SARSA
🎮 強化學習的基本元素
Agent（智能體）做決策的主體，如機器人、遊戲角色
Environment（環境）Agent 互動的世界，如棋盤、遊戲場景
State s（狀態）目前環境的快照，如棋盤目前局面
Action a（動作）Agent 可以採取的行為，如上下左右
Reward r（獎勵）環境回饋的分數，正分鼓勵、負分懲罰
Q(s,a)（Q 值）在狀態 s 採取動作 a 的預期長期總獎勵
Q*
Q-Learning
Off-policy TD Control
更新 Q 值時，假設下一步「一定選最優動作」（max Q），不管實際走哪條路。
Q(s,a) ← Q(s,a) + α [ r + γ · maxQ(s',a') − Q(s,a) ]
↑ 用下一狀態所有動作中 Q 值最大的那個
🔑 Off-policy 的意思
行為策略（實際走路的方式）：ε-greedy，偶爾隨機探索
學習目標（更新 Q 用的）：假設下一步永遠走最優解
兩者不同 → Off-policy（脫離策略）
🎮 國中生版本
下棋時，Q-Learning 更新分數的方式是：「假設我下一步一定走最好的那步，那這步值多少分？」。就算它有時候會隨機亂走探索，但學習時永遠假設下一步是最優解。學到的是「理論上最好的策略」，比較大膽。
懸崖行走（Cliff Walking）行為：貼著懸崖邊走最短路——因為學習時假設不會失足，路徑最優但有風險
Off-policy學最優策略DQN 的基礎

SARSA
On-policy TD Control
更新 Q 值時，用「實際採取的下一個動作」a' 來計算，不假設最優。
Q(s,a) ← Q(s,a) + α [ r + γ · Q(s',a') − Q(s,a) ]
↑ a' 是實際走的下一步（不是 max，是真實動作）
🔑 On-policy 的意思 + SARSA 名字來源
行為策略與學習目標用同一個策略 → On-policy（跟著策略走）
學的是「自己實際在跑的策略」的價值
名字來自更新用到的五元組：
State → Action → Reward → State → Action
🎮 國中生版本
SARSA 更新分數時，用的是「我下一步真的走了哪步」。如果下一步是隨機亂走的，那個「亂走」的後果也會被算進去。學到的是自己「實際行為的結果」，比較保守謹慎。
懸崖行走（Cliff Walking）行為：繞遠路走安全路徑——因為學習時考慮自己真的可能失足，路徑較長但穩健

// DDPG — Actor-Critic 雙網路架構
💡 為什麼需要 DDPG？
DQN 的限制：只能處理離散動作（左/右/跳）。機械手臂角度、油門大小這類連續數值無法用 argmax 選動作。
DDPG 的解法：用 Actor 神經網路直接輸出連續動作值，Critic 評估這個動作的好壞，兩者互相配合。
🎭
Actor（演員網路）
Policy Network — 決定做什麼
輸入狀態 s，輸出確定性連續動作 μ(s)（一個具體數值，不是機率分布）。
a = μ(s; θᵘ)　← θᵘ 是 Actor 的參數
目標：找到讓 Q 值最大的動作
更新：∇Q 對 θᵘ 求梯度（Policy Gradient）
🎭 國中生版本
Actor 就像「選手」，看到目前狀況，直接決定要做什麼動作。輸出的是一個具體數值（如「把手臂轉 47.3°」），不是選擇題。靠 Critic 的評分來學習怎麼做更好。
輸入：s輸出：μ(s) 連續動作
🎯
Critic（評論家網路）
Q-Value Network — 評價好不好
輸入狀態 s 和動作 a，輸出Q(s,a) 值（這個動作的長期預期獎勵）。
Q = Q(s, a; θᴼ)　← θᴼ 是 Critic 的參數
目標：準確估計動作的長期價值
更新：TD-error = Q預測 vs (r + γQ(s', μ(s')))
🎯 國中生版本
Critic 就像「教練」，看到選手的動作，給一個分數（Q 值）：「這個動作長遠來看值 8.3 分」。Actor 根據這個分數調整自己的動作策略。教練學得越準，選手就進步越快。
輸入：s + a輸出：Q(s,a) 數值
🔄 完整訓練流程
① Actor 看到狀態 s → 輸出動作 a = μ(s)
② 執行動作，獲得獎勵 r，進入下一狀態 s'
③ Critic 評估 Q(s, a) → 這個動作長期值多少分
④ Critic 更新：用 TD-error 讓 Q 估計更準確
⑤ Actor 更新：沿 ∇Q 方向調整，往讓 Q 更大的動作靠近
⑥ 探索：動作加入 Ornstein-Uhlenbeck 雜訊避免陷入局部最優
DQNDDPG
動作空間離散（上/下/左/右）連續（0.0 ～ 360.0°）
選動作方式argmax Q（選最大的格子）Actor 網路直接輸出數值
網路數量1 個 Q 網路Actor + Critic 共 2 個
探索方式ε-greedy（隨機選動作）動作 + OU 雜訊
適用場景遊戲、棋類機械手臂、自動駕駛、控制
💡 一句話記：Actor 決定「做什麼」輸出動作；Critic 評價「有多好」輸出 Q 值；Actor 靠 Critic 的梯度變得更聰明。
// 遷移學習 — 站在巨人的肩膀上
💡 核心概念
把在大資料集上學好的模型（預訓練模型）直接拿來用，只需要少量新資料微調，就能解決新問題。不用從零開始。
沒有遷移學習
從零訓練 → 需要百萬筆資料 + 幾週時間 + 大量算力
有遷移學習
借用已訓練好的模型 → 幾千筆資料 + 幾小時搞定
🔧
Fine-tuning（微調）
Pre-trained Model Fine-tuning
把預訓練模型（如 ResNet、BERT）拿來，在新任務的資料上繼續訓練，讓模型微調參數適應新問題。
預訓練模型 → 替換最後幾層 → 小 lr 繼續訓練

Feature Extraction（特徵萃取）
Frozen Backbone
把預訓練模型當固定的特徵提取器，凍結大部分層的參數，只訓練新加的分類頭。
凍結所有層 → 只訓練最後的 classifier
新資料很少、算力不足時適用，比 Fine-tuning 快很多。
❄️ 國中生版本
把預訓練模型整個「冷凍」住，只在最後接一個新的分類層來訓練。就像借一台相機（鏡頭不動），只換濾鏡。資料太少時用這個比 Fine-tuning 更安全，不容易過擬合，速度也快很多。

// 激活函數（Activation Function）
⚡ 為什麼需要激活函數？
神經網路每一層在做：
輸入 × 權重 + 偏差 → 激活函數 → 輸出

沒有激活函數的話，不管疊幾層，整個神經網路就只是一個線性方程式，跟一層沒差別。激活函數加入非線性，讓網路能學複雜的規律。
🏫 國中生版本
就像人腦的神經元：接收到夠強的訊號才會「觸發」，不然就靜默。激活函數決定這個神經元要不要把訊號往下傳、傳多少。
ReLU
ReLU
Rectified Linear Unit
🏫 國中生版本
負的全砍成 0，正的原樣通過。就像一道單向門，只讓正面訊號進來。
f(x) = max(0, x)
x < 0 → 輸出 0
x ≥ 0 → 原樣輸出
優點：梯度不會消失（正數區梯度=1），計算快
缺點：「死亡 ReLU」：負數永遠輸出 0，那個神經元可能永遠不再學習
口訣：「負的全砍掉，正的原樣過」
隱藏層首選；現代深度學習的標準配備
σ
Sigmoid
Logistic Function
🏫 國中生版本
把任何數字壓縮到 0～1 之間，輸出可以直接當成機率。很大的正數 → 接近 1；很大的負數 → 接近 0。
f(x) = 1 / (1 + e⁻ˣ)　輸出範圍：(0, 1)
優點：輸出是機率，適合二分類輸出層
缺點：深層隱藏層會梯度消失（梯度最大只有 0.25）
口訣：「把任何數字壓成 0～1 的機率」
輸出層二分類首選；隱藏層深了會梯度消失
SMax
Softmax
Normalized Exponential Function
🏫 國中生版本
有三個類別，Softmax 把分數換算成「各類別的機率」，加起來永遠是 100%。分數最高的那個機率就最大。
softmax(xᵢ) = eˣⁱ / Σeˣʲ

[2.0, 1.0, 0.1] → [0.70, 0.24, 0.06]
加總 = 1.0 ✓

🔍 為什麼這樣選？
為什麼隱藏層不用 Sigmoid？— 梯度消失
Sigmoid 的梯度最大只有 0.25。反向傳播時梯度一層層相乘： 0.25 × 0.25 × 0.25 × 0.25 = 0.004（10層後幾乎是0） 前幾層完全學不到東西。ReLU 正數區梯度 = 1，不會越乘越小。
為什麼隱藏層不用 Softmax？— 互相競爭
Softmax 強迫所有輸出加總 = 1。隱藏層的神經元需要各自獨立學不同特徵，但 Softmax 讓它們互相壓制：一個大了其他就得變小，限制了表達能力。
輸出層可以用 ReLU 嗎？
分類任務不適合，因為 ReLU 輸出沒有上限，無法解釋為機率，也沒辦法計算 Cross Entropy loss。
特例：回歸任務預測「不能為負的值」（如房價、銷售量）時，輸出層可以用 ReLU。
位置任務推薦原因
隱藏層所有任務ReLU梯度不消失、計算快
輸出層二分類Sigmoid輸出 0～1 機率
輸出層多分類Softmax多類別機率，加總=1
輸出層回歸（值≥0）ReLU輸出不能為負
輸出層回歸（任意值）無（線性）不限範圍
// 超參數調整（Hyperparameter Tuning）
💡 什麼是超參數？
模型訓練前需要人工設定的參數，訓練過程不會自動更新。例如：學習率、樹的深度、Dropout 比率、隱藏層數量。調整超參數的目標是找出讓驗證集表現最好的組合。
🔲
Grid Search（網格搜尋）
Exhaustive Search over Parameter Grid
列出每個超參數的所有候選值，窮舉所有組合，每個都跑一次訓練，取最好的。
lr ∈ {0.1, 0.01, 0.001} × depth ∈ {3, 5, 7}
→ 共 3 × 3 = 9 組，全部跑過
🔲 國中生版本
把所有選項列成一張表格，每格都試一遍。保證找到表格裡最好的組合，但超參數一多，格子數量爆炸（3個參數各5選項 = 125組），非常耗時。
保證最優（候選內）組合爆炸
🎲
Random Search（隨機搜尋）
Random Sampling over Parameter Space
在超參數空間中隨機抽樣 N 組，只跑 N 次，取最好的。
從連續範圍均勻抽樣：
lr ~ Uniform(0.0001, 0.1)
depth ~ RandInt(3, 10)
🎲 國中生版本
不全試，隨機抽幾組來試。研究顯示：如果只有少數幾個超參數真的重要，隨機搜尋比格搜尋更有效率——因為格搜尋會在不重要的參數上浪費格子。實務上比 Grid Search 更常用。
效率高實務首選
🧠
Bayesian Optimization（貝葉斯優化）
Surrogate Model + Acquisition Function
用過去試過的結果建立代理模型（surrogate），預測哪個超參數組合最有可能改善，智慧地選下一個要試的點。
Surrogate: p(score | params) — Gaussian Process
Acquisition fn: 平衡「探索未知」vs「利用已知好」
每輪更新代理模型 → 再選下一組
🧠 國中生版本
不是亂猜，而是從過去的實驗結果學習「哪個區域的參數容易表現好」，然後聰明地選下一個最值得試的點。就像有經驗的老師猜考題，不是每題都算，而是挑最可能考的題目。只需少量實驗就能找到好結果。
最少實驗次數計算資源昂貴時Optuna / Hyperopt
🏆
Successive Halving / Hyperband
Early Elimination Strategy
先用少量資源跑所有候選，淘汰表現差的，只給表現好的更多資源繼續跑。像比賽的淘汰制。
第1輪：100組候選 × 10 epochs → 保留前50
第2輪：50組候選 × 20 epochs → 保留前25
最終：只有少數幾組跑完整訓練
🏆 國中生版本
像運動會多輪淘汰賽：先讓所有人跑 100 公尺，只讓前半段的人晉級，給他們更多訓練時間，再淘汰，一直到最後只剩冠軍。不讓明顯爛的參數浪費完整的訓練資源。
快速淘汰大規模搜尋
方法試幾組是否利用歷史適合情境
Grid Search全部組合否參數少、候選有限
Random Search固定 N 組否參數多、連續範圍
Bayesian Optim.聰明地選✓ 利用代理模型每次實驗代價高昂
Hyperband分輪淘汰部分候選很多但想省資源
// Learning Rate Scheduler（學習率排程）
💡 為什麼要動態調整學習率？
訓練早期：lr 大一點，快速下坡，遠離壞的初始位置
訓練後期：lr 小一點，在最低點附近精細收斂，不要跳過去
📉
Step Decay / Exponential Decay
固定步驟降低學習率
每隔固定 epoch 或按指數衰減，把學習率降低一個倍數。
Step: lr = lr₀ × γ^(epoch/step_size)
Exponential: lr = lr₀ × e^(−λt)
📉 國中生版本
每跑 30 個 epoch 就把學習率砍半。最直覺的方法，就像跑步比賽：前半程全力衝，後半程保留體力細修。缺點是要手動決定何時降、降多少。
簡單直覺需手動調
🔥
Cosine Annealing（餘弦退火）
Cosine Decay with Optional Restart
學習率按餘弦曲線從最大值平滑下降到最小值，可搭配週期重啟（Warm Restart）。
lr_t = lr_min + ½(lr_max − lr_min)(1 + cos(πt/T))
t = 當前 step，T = 週期長度
🔄 Warm Restart（SGDR）是什麼？
學習率跑完一個週期降到最小值後，不是繼續保持在低點，而是「重置回高值」再重新衰減，形成多個週期的鋸齒波形。
沒有 Warm Restart
lr 一路衰減到底，卡在局部最小值就出不來
有 Warm Restart
每次重置讓模型有機會跳出局部最小，再重新收斂到更好的位置
週期 1：lr_max → lr_min（T₁ steps）
週期 2：lr_max → lr_min（T₂ = 2×T₁ steps，週期可變長）
週期 3：lr_max → lr_min（T₃ = 2×T₂ steps）…
🔥 國中生版本
學習率像波浪一樣平滑下降，降到谷底後不停在那裡，而是重置回高點再降一次（Warm Restart）。重置時的大學習率讓模型有機會跳出卡住的地方，重新找更好的山谷；再衰減時精細收斂。每個週期可以越來越長，讓後期的每次重啟都有更充分的收斂時間。
⭐ 現代主流組合：通常搭配 Warmup（見下張卡）→ Cosine Annealing，BERT、ViT、LLaMA 等大模型幾乎全部採用此組合。
平滑衰減現代主流SGDR
🌡️
Warmup + Decay
Linear Warmup → 衰減
訓練最開始幾步先用非常小的學習率「熱身」，線性升到目標值，再衰減。
Warmup 階段（前 N steps）：lr 線性從 0 升到 lr_max
之後：cosine / linear 衰減
🌡️ 國中生版本
模型剛開始訓練時參數是隨機的，如果一開始就用很大的學習率，容易把模型「震壞」。Warmup 讓模型先慢慢暖機，再全力訓練。BERT、GPT 等大模型幾乎都用這個。
⭐ 現代主流組合：Warmup 之後接 Cosine Annealing（見上張卡），兩者合用是大模型與 ViT 時代的業界標準。
Transformer 標配大模型必用
📊
ReduceLROnPlateau
根據驗證集表現自動降低
監測驗證集指標，若連續 N 個 epoch 沒有改善，就自動降低學習率。
if val_loss 連續 patience 個 epoch 沒降低:
lr = lr × factor（通常 0.1~0.5）
📊 國中生版本
不需要事先規劃，模型自己看成績決定要不要降學習率。「已經 5 個 epoch 成績沒進步了，看來學習率太大跳不進去，把它縮小 10 倍再試試」。適合不確定訓練多久的情況。
自適應不確定訓練長度
🔄
Cyclic LR（循環學習率）
Cyclical Learning Rate
學習率在最小值與最大值之間反覆循環，讓模型能跳出鞍點和局部最小值。
三角波循環：lr 在 [lr_min, lr_max] 線性上下
也有 exp_range 等變體
🔄 國中生版本
學習率像心電圖，不斷高低交替。高的時候幫助跳出局部最小，低的時候精細收斂。好處是不需要靠直覺猜學習率該多大，在某個合理範圍內循環就夠了。
跳出局部最小參數需調試
方法決定時機特點適合情境
Step / Exp Decay提前設定簡單直接訓練 epoch 已知
Cosine Annealing提前設定平滑，可重啟現代 CV / NLP 任務
Warmup + Decay提前設定大模型必用Transformer 類模型
ReduceLROnPlateau自動觸發無需規劃不確定收斂步數
Cyclic LR循環交替跳出局部最小快速探索學習率

考試考爛了，老師從總分往回找：「扣 10 分 → 第三大題錯 → 第二小題概念錯 → 某公式記錯了」。

𝑃
Bayes' Theorem
貝葉斯定理
🌧️ 國中生版本
你覺得今天下雨機率 30%（先驗）。突然看到外面烏雲密佈，你把機率更新成 80%（後驗）。
不是一次算出答案，而是每次看到新資料就修正一次猜測。
P(A|B) = P(B|A) · P(A) / P(B)

後驗 ∝ 概似 × 先驗
🔑 貝葉斯 4 大角色
Prior — P(H)
看到證據之前的猜測
例：下雨機率 30%
Likelihood — P(E|H)
假設 H 成立時，E 出現的機率
例：有下雨時，看到烏雲的機率
Marginal — P(E)
不管 H 是否成立，E 出現的總機率
例：看到烏雲的機率（正規化分母）
Posterior — P(H|E)
看到證據之後更新的猜測
例：看到烏雲後，下雨機率 80%
P(H|E) = P(E|H) × P(H) / P(E)
Posterior = Likelihood × Prior ÷ Marginal
ML 應用：樸素貝葉斯分類器、貝葉斯超參數優化、MCMC 推論。

λ
特徵值 & 特徵向量
Eigenvalue & Eigenvector
對一個方陣 A，如果有一個非零向量 v，使得：
A · v = λ · v
v = 特徵向量（Eigenvector）
λ = 特徵值（Eigenvalue）
λ 國中生版本
把矩陣 A 想成「一台拉伸機器」，把向量丟進去，大部分向量出來後方向會歪掉。
但有幾個「特殊方向」的向量丟進去，出來後方向完全不變，只有長度變長或縮短——這就是特徵向量。
那個「變了幾倍」的數字，就是特徵值。

特徵值越大 = 這個方向被拉得越長 = 資料在這個方向變化越大 = 越重要
PCA 就是找出特徵值最大的幾個方向，把資料投影過去，就完成降維了。
🔑 核心直覺：矩陣「不改變方向，只改變大小」的特殊向量
特徵向量 v：
矩陣 A 作用在這個向量上之後，方向不變（可能反向），只有長度縮放。這個向量代表資料「最重要的方向」。
特徵值 λ：
那個縮放的倍數。λ 越大，代表資料在這個方向的變異量越大（資訊越多）；λ 越小，這個方向越不重要。
λ 國中生版本 — 用身高體重來理解
想像 1000 個人的「身高 vs 體重」資料點畫在平面上，會形成一個斜的橢圓形雲。

這個橢圓有兩個軸：
 · 最長的軸（點最分散的方向）→ 第一個特徵向量，特徵值最大
 · 最短的軸（點最集中的方向）→ 第二個特徵向量，特徵值較小

特徵值告訴你「這個方向有多重要」：特徵值 6 的方向比特徵值 1 的方向重要 6 倍，保留前者就能保留最多資訊。這正是 PCA 降維的核心邏輯。
數值範例
A = [[3, 1], [0, 2]]　特徵值：λ₁=3, λ₂=2
λ₁=3 的特徵向量 v₁=[1, 0]：A·[1,0] = [3,0] = 3·[1,0] ✓　方向不變，長度變 3 倍
λ₂=2 的特徵向量 v₂=[1,-1]：A·[1,-1] = [2,-2] = 2·[1,-1] ✓　方向不變，長度變 2 倍

特徵值分解（EVD）
Eigenvalue Decomposition
把方陣 A 分解成特徵向量矩陣與特徵值對角矩陣的乘積。
A = Q Λ Q⁻¹
Q：各列為特徵向量（方向）
Λ：對角線為特徵值（大小）
Q⁻¹：Q 的逆矩陣
📐 EVD 最重要的對象：協方差矩陣是什麼？
協方差（Covariance）= 兩個特徵一起變動的程度：
身高↑ 體重也↑ → 正協方差 ；運動量↑ 體脂↓ → 負協方差 ；身高↑ 成績沒變 → 協方差≈0
協方差矩陣 C（3個特徵）：
        身高   體重   成績
身高 [ 4.0    2.5    0.1 ]
體重 [ 2.5    3.0    0.2 ]
成績 [ 0.1    0.2    1.5 ]
↑ 對角線 = 自己的變異數；非對角線 = 兩兩之間的協方差
協方差矩陣一定是方陣且對稱（n 個特徵 → n×n），因此可以做 EVD。
對它做 EVD → 特徵向量 = 資料最分散的方向 → 這就是 PCA 的完整流程。
EVD 實際應用
PCA 降維：對協方差矩陣做 EVD，特徵向量=主成分方向，特徵值=重要程度
Google PageRank：網頁連結矩陣的最大特徵向量 = 每個網頁的重要性分數
人臉辨識（Eigenface）：人臉矩陣做 EVD，每張臉用少數特徵向量組合表示
振動/結構分析：特徵值 = 橋梁共振頻率，特徵向量 = 振動模式
Markov Chain：長期穩定機率分布 = 特徵值為 1 的特徵向量
限制：只能對方陣（行數 = 列數）使用；非方陣要改用 SVD

EVD 就是問：「這個矩陣最喜歡把什麼方向放大？放大幾倍？」
拆解成三步：換到特徵向量的座標系 → 在那裡做縮放 → 換回來。

奇異值分解（SVD）
Singular Value Decomposition
任意矩陣（包括長方形）都能分解為三個矩陣的乘積，是特徵值分解的通用版本。
A = U Σ Vᵀ
U（m×m）：左奇異向量，輸入空間的方向
Σ（m×n）：對角線為奇異值（≥0，由大到小排列）
Vᵀ（n×n）：右奇異向量，輸出空間的方向
🔬 奇異值 vs 特徵值
特徵值（EVD）
只對方陣有意義
可以是負數或複數
透過 A·v = λ·v 定義
奇異值（SVD）
對任意矩陣有意義
永遠 ≥ 0
= 特徵值開根號（對稱正定矩陣）
低秩近似：只保留前 k 個最大奇異值，重建出「壓縮版」的矩陣
Aₖ = U[:,:k] · Σ[:k,:k] · Vᵀ[:k,:]　← 最佳 k 秩近似
Σ 國中生版本
把任何一張矩陣（想像成一張圖片）分解成三個動作：「旋轉 → 拉伸/壓縮 → 再旋轉」。Σ 的對角線數字（奇異值）告訴你每個方向被拉了多少。

最妙的地方：只保留前幾個最大的奇異值，就能用少量數字「重建」出原本矩陣的近似版——這就是圖片壓縮、推薦系統、降維的原理。
SVD 的實際應用
PCA：對資料矩陣做 SVD，右奇異向量 = 主成分方向
推薦系統：分解「用戶×電影」評分矩陣，找潛在因子
影像壓縮：只保留前 k 個奇異值重建圖片，減少儲存量
自然語言：LSA（潛在語義分析）對詞頻矩陣做 SVD
數值計算：求偽逆（Moore-Penrose）、解方程組的穩定方法

所有優化器都在解決同一個問題：怎麼走到山谷最低點？
最基本的走法（SGD）是每次感覺坡度往低處走一步。優化器就是在這個基礎上，加各種「輔助功能」讓你走得更快、更準、更不容易卡住。

SGD
Stochastic Gradient Descent — 隨機梯度下降
⛰️ 國中生版本
閉眼站在山上，每次用腳感覺坡度，往低的地方走一步。沒有任何輔助，純靠感覺。
最基本的優化器。每次只用一小批資料算梯度，然後往梯度的反方向走一步。
w ← w − η · ∇L(w)
優點：簡單、記憶體少、有時泛化比 Adam 好
缺點：需要手動調 learning rate，收斂慢、容易卡在鞍點
口訣：「最原始的下坡，沒有任何輔助」
適合：簡單模型、想要最大控制權時
🏃
SGD + Momentum
動量梯度下降
⛰️ 國中生版本
把一顆球放在山上，讓它滾。球有慣性，之前滾的方向會帶著它繼續走，遇到小坑也不容易卡住，直接滾過去。
在梯度下降加入「慣性」，之前的方向會影響現在的走向。
v ← β·v + η·∇L(w)
w ← w − v
β 通常設 0.9
優點：收斂更快、更不容易卡在局部最小值
缺點：多一個超參數 β 要調
口訣：「滾球下山，有慣性不容易被坑卡住」
適合：CV 任務，ResNet 訓練常用
RMS
RMSProp
Root Mean Square Propagation
⛰️ 國中生版本
你有一雙智慧鞋，走陡坡自動煞車（步伐縮小），走平路自動加速（步伐放大），不用自己調，鞋子幫你搞定。
對每個參數自動調整學習率，梯度大的縮小步伐，梯度小的放大步伐。
v ← β·v + (1−β)·(∇L)²
w ← w − (η / √v+ε) · ∇L
優點：適合非穩態問題，RNN 效果特別好
缺點：沒有動量，現在多被 Adam 取代
口訣：「跑太快的腳踩煞車，跑太慢的腳踩油門」
適合：RNN、序列模型
⭐
Adam 最常用
Adaptive Moment Estimation
⛰️ 國中生版本
把「滾球的慣性（Momentum）」和「智慧鞋的自動調速（RMSProp）」合在一起。又有慣性不卡住，又會自動調步伐大小。幾乎不需要自己設定，開箱即用。
Momentum + RMSProp 的結合——Adam 內部同時維護兩個數字：
m 「我最近大概往哪個方向走？」→ 來自 Momentum，管方向
v 「我最近的梯度大概多大？」→ 來自 RMSProp，管步伐大小
更新時：用 m 決定方向，用 v 決定步伐 → 兩個問題一次解決
m ← β₁·m + (1−β₁)·∇L ← 動量
v ← β₂·v + (1−β₂)·(∇L)² ← 自適應
w ← w − η · m̂ / (√v̂ + ε)
β₁=0.9, β₂=0.999, η=1e-3
優點：收斂快、幾乎不需要調 learning rate、適合大多數任務
缺點：有時泛化比 SGD 差（過度適應訓練集）
口訣：「有慣性又會自動調步伐，萬能選手」
適合：幾乎所有任務的預設起點，NLP 尤其強

AdamW
Adam + Weight Decay 解耦
⛰️ 國中生版本
Adam 有個 bug：原版把 L2 懲罰混進梯度裡，但 RMSProp 看到「梯度變大了」會自動縮小步伐，剛好把 L2 的效果抵消掉——加了等於沒加。

AdamW 的修法：L2 不混進梯度，單獨處理。
❌ Adam（有 bug）
梯度 = 原梯度 + λ·w
→ RMSProp 看到梯度變大
→ 自動縮步伐
→ L2 效果被抵消 😵
✓ AdamW（修好了）
步驟1：用原梯度更新
步驟2：直接縮小 w
→ 兩件事分開做
→ L2 真正有效果 ✓
「參數不能長太大」的意思：參數（w）是模型裡的數字，太大代表模型太複雜、在死記資料。每步把 w 縮小一點點（× 0.99），就像每天提醒自己「別死記，要真的懂」。
L2 正則化從梯度裡獨立出來，不被 RMSProp 干擾，效果才真正發揮。
w ← w − η · (m̂/(√v̂+ε) + λ·w)
λ = weight decay 係數
優點：正則化更正確，泛化通常比 Adam 好
適用：GPT、BERT 等 Transformer 模型的標準選擇
口訣：「Adam 修好體重管理的升級版」
適合：Transformer、大型語言模型

// 實戰應用：用 VAE 監控金融風控模型
📋 情境
你用 2020 年的客戶資料訓練了一個「會不會還款」的風控模型，上線後分類錯誤率越來越高。 原因是：現實客戶的資料分佈跟當初訓練的不一樣了（年齡、收入、消費習慣都變了）。 這個現象叫 Data Drift（資料漂移）。
💡 為什麼用 VAE 偵測？
原始資料有幾百個特徵，直接比較很複雜。VAE 把幾百維壓縮成 2～10 維的潛在空間，在小空間裡比較距離，簡單又有效。
直接比較原始資料 ✗
年齡、收入、消費紀錄…幾百個維度，很難判斷「漂移了多少」
VAE 潛在空間比較 ✓
壓縮成 8 維，計算分佈距離，超過閾值就警報
⚙️ 具體做法
Step 1
用訓練集資料跑過 VAE，記錄潛在空間的「正常分佈」（平均值 μ、範圍 σ）
Step 2
每天把新進來的資料也跑過同一個 VAE，看它落在潛在空間的哪裡

Step 4

🎯 目的是什麼？

ANOVA 和 F 檢定是什麼關係？
ANOVA（變異數分析）就是「用 F 檢定比較三組以上平均值」的分析方法。
F 檢定是計算公式，ANOVA 是使用這個公式的方法——就像「加法」和「把兩個數加起來」，說法不同但是同一件事。

// 多重共線性（Multicollinearity）
≈
多重共線性
Multicollinearity — 自變數之間互相太像
≈ 國中生版本 — 記憶口訣
「三個人說同一件事，模型不知道聽誰的」
你想預測一個人有多健康，用了三個特徵：每週運動時數、每週跑步時數、每週健身時數。
問題是：跑步和健身本來就包含在「運動」裡，三個特徵幾乎在說同一件事。
模型不知道把功勞分給誰 → 係數變得奇怪、不穩定。
⚠️ 會造成什麼問題？
運動時數　權重 = +10
跑步時數　權重 = −8　← 明明有益健康，卻出現負值！
健身時數　權重 = +9　← 三者互相抵消，難以解釋
三個特徵搶同一份功勞，模型把權重分散抵消，導致：
· 係數方向可能反常（明明正相關卻是負係數）
· 係數不穩定（資料稍微變動，權重就大幅波動）
· 難以用係數解釋「哪個特徵真的重要」
🔬 怎麼檢測？VIF
VIF（Variance Inflation Factor）
衡量某特徵能被其他特徵預測的程度：
VIF = 1　→ 完全沒有共線性
VIF = 5　→ 中度，開始注意
VIF > 10　→ 嚴重，必須處理
🔧 怎麼解決？
刪除冗餘特徵：跑步和健身二選一
PCA 降維：三個合成一個「運動主成分」
L1 正則化：自動把冗餘係數砍成 0
Ridge（L2）：讓係數縮小、穩定下來
💡 注意：多重共線性影響的是係數的解釋，不一定影響模型的預測能力。如果只要預測準確、不需要解釋係數，有時可以接受。但如果目標是「哪個特徵最重要」，就必須處理。

平穩性（Stationarity）
ARIMA 建模的前提條件
平穩的時間序列：均值、變異數、自相關結構都不隨時間改變。ARIMA 要求資料必須平穩才能建模。
✓ 平穩序列
上下波動固定，沒有明顯趨勢或季節性
✗ 非平穩序列
持續上升 / 季節波動 / 變異數越來越大
～ 國中生版本
就像量體溫，正常人在 36～37°C 波動（平穩）。如果體溫每天都在漲（趨勢），就是非平穩。差分（d）就是把「今天 − 昨天」的差值拿來分析，消除趨勢讓它變平穩。

ACF & PACF
自相關函數 & 偏自相關函數
用來判斷時間序列中「現在和過去幾期有多大關聯」，是選擇 ARIMA 參數 p、q 的主要依據。
ACF（Autocorrelation Function）— 自相關函數
現在的值和「n 期前的值」的相關程度。若殘差的 ACF 在多個時滯顯著不為 0 → 模型沒學完規律。
PACF（Partial Autocorrelation Function）— 偏自相關函數
排除中間各期的影響後，現在和「n 期前」的直接相關程度。
📐 如何用 ACF/PACF 選參數？
現象代表動作
ACF 緩慢衰減需要差分（非平穩）增加 d
ACF 在 q 階後截尾MA(q) 結構設 q 值
PACF 在 p 階後截尾AR(p) 結構設 p 值
殘差 ACF 多個顯著模型配適不足調整 p 或 q
↔ 國中生版本
ACF 就是問「今天的銷售量和 3 週前的銷售量有多相關？」如果殘差的 ACF 還是很高，代表模型沒把這個規律學走，還有資訊沒用到。

ARIMA（p, d, q）
AutoRegressive Integrated Moving Average
整合三種成分的時間序列預測模型，適合無季節性的單變量序列。
ARIMA(p, d, q)
p = AR 階數（用前幾期的值預測）
d = 差分次數（讓序列變平穩）
q = MA 階數（用前幾期的誤差修正）
p（AR）
AutoRegressive
用過去 p 期的值預測現在。
由 PACF 截尾判斷。
y_t = φ₁y_{t-1} + ... + φ_p y_{t-p}
d（I）
Integrated（差分）
對原始序列做幾次差分才平穩。
d=1：今天 − 昨天
d=2：再差分一次
q（MA）
Moving Average
用過去 q 期的預測誤差修正。
由 ACF 截尾判斷。
y_t = ε_t + θ₁ε_{t-1} + ... + θ_q ε_{t-q}
✅ 好模型的殘差 = 白噪音（White Noise）
白噪音條件（全部要滿足）
均值 = 0
變異數固定
ACF 各時滯 ≈ 0（彼此不相關）
殘差異常 → 配適不足
ACF 多個時滯顯著 → 調整 q
PACF 多個時滯顯著 → 調整 p
週期性波動 → 考慮 SARIMA
∿ 國中生版本
ARIMA 就像一個「有記憶的預測機器」：AR 部分說「上週賣 100，這週大概也差不多」（看過去的值）；MA 部分說「上週預測錯了 10 個，這週要修正」（看過去的誤差）；d 是先把資料「去趨勢」才能用。殘差是否為白噪音，是判斷模型好不好的標準。

// 資料漂移偵測（Data Drift Detection）
💡 什麼是資料漂移？
訓練時：顧客平均年齡 35 歲、消費集中 500~2000 元
上線後：顧客平均年齡 25 歲、消費集中 100~500 元
輸入特徵的分布改變了 → 模型用舊規律預測新行為 → 準確率下降
重訓練是治療，偵測工具是診斷——要先確認漂移，再決定是否重訓練。
KL
KL 散度（KL Divergence）— 偵測資料漂移的核心工具
Kullback-Leibler Divergence
直接量化**兩個分布之間的差異**：把訓練時的特徵分布和現在的特徵分布相比，差距越大代表漂移越嚴重。
KL(P ‖ Q) = Σ P(x) · log( P(x) / Q(x) )
P = 訓練時的特徵分布　Q = 目前線上的特徵分布
KL = 0 → 無漂移；KL 越大 → 漂移越嚴重
KL 國中生版本
想像訓練資料是「舊地圖」，新進來的資料是「現實地形」。KL 散度就是在量「舊地圖和現實差了多遠」。差距接近 0 → 地圖還準；差距很大 → 地圖已經過時，需要更新（重新訓練）。
🧰 完整的資料漂移偵測工具箱
方法適用特徵說明告警門檻
KL 散度 連續 / 離散 量化兩分布差異，偵測最直接 依業務設定
PSI（族群穩定指數） 連續（分桶後） 業界最常用，PSI = Σ (P-Q)·ln(P/Q) PSI > 0.2 → 嚴重
KS 檢定 連續特徵 統計檢定兩組樣本是否來自同一分布 p-value < 0.05
卡方檢定 類別特徵 檢定類別比例是否改變 p-value < 0.05
Wasserstein 距離 連續特徵 比 KL 更穩定（KL 對 0 機率敏感） 依業務設定
VAE 重建誤差 高維 / 多特徵 壓縮到潛在空間後比較距離（見生成模型頁） 誤差 > 閾值
⚠️ 常見誤解：
重新訓練 = 解決漂移的治療方法，不是偵測工具
提升模型複雜度 = 加劇過擬合，對漂移無效
增加測試資料 = 讓評估更穩定，但不能告訴你分布差了多少
→ 正確流程：先用 KL 散度 / PSI 診斷有漂移 → 再決定是否重訓練

逐步擴大用戶覆蓋範圍

第 4 階段：100% 用戶 → 全量上線

Acc
Accuracy（準確率）
整體猜對的比例
🏫 國中生版本
100 題猜對 90 題，準確率 = 90%。最直覺的指標，但資料不平衡時會騙人。
Accuracy = (TP + TN) / (TP + TN + FP + FN)
⚠️ 陷阱：1000 人中只有 10 個有病，模型全猜「沒病」也有 99% 準確率，但完全沒用。
口訣：「猜對幾題除以總題數，資料平衡才可信」
適合：類別分佈平衡時；不平衡時改用 F1 或 AUC
Pre
Precision（精確率）
預測為正的裡面，真的是正的比例
🏫 國中生版本
你說「這 10 封是垃圾郵件」，其中 9 封真的是。Precision = 9/10 = 90%。「我說是的，有幾個真的是？」
Precision = TP / (TP + FP)
Precision 低 → 誤報多（把正常郵件當垃圾）。重視 Precision 的情境：垃圾郵件過濾、法律文件審查。
口訣：「我說是的，有幾個真的是？」
關注：誤報（FP）的代價高時用 Precision
Rec
Recall（召回率）
實際為正的裡面，被找出來的比例
🏫 國中生版本
100 個真的有病的人，你找出 90 個。Recall = 90/100 = 90%。「真正的壞人，我抓到幾個？」
Recall = TP / (TP + FN)
Recall 低 → 漏報多（把有病的人說成沒病）。重視 Recall 的情境：癌症篩檢、詐騙偵測。
口訣：「真正的壞人，我抓到幾個？」
關注：漏報（FN）的代價高時用 Recall
⚖️ Precision vs Recall：魚與熊掌
提高 Precision → 閾值提高 → 只有非常確定才預測正類 → FP↓ 但 FN↑ → Recall↓
提高 Recall → 閾值降低 → 寬鬆認定正類 → FN↓ 但 FP↑ → Precision↓
重視 Precision 的情境
誤報代價高：
垃圾郵件過濾（把正常信刪掉很糟）
法律文件推薦（推錯文件浪費時間）
重視 Recall 的情境
漏報代價高：
癌症篩檢（漏掉一個可能死人）
詐騙偵測（漏掉一筆損失很大）
F1
F1 Score
Precision 和 Recall 的調和平均
🏫 國中生版本
Precision 和 Recall 常常魚與熊掌不可兼得。F1 是兩者的平衡分數，任何一個很爛，F1 就會很低。
F1 = 2 × (Precision × Recall) / (Precision + Recall)
Precision=1.0, Recall=0.1
F1 = 0.18 ← 很低
Precision=0.9, Recall=0.8
F1 = 0.85 ← 均衡好
口訣：「精確和召回的平衡分，一個爛就全爛」
不平衡資料集的首選指標；F-beta 可以調整兩者的權重
M/F1
Macro F1 vs Micro F1
多分類任務的 F1 合併方式
🏫 國中生版本
Macro F1：班上 3 組做報告，不管每組幾個人，每組分數一樣重要。10 人大組和 2 人小組的分數權重相同。小組換一個人分數就差很多 → 波動性高。
Micro F1：按人頭算，10 人大組每個人都算到，2 人小組只算 2 個人。整體結果由多數人決定 → 比較穩定。
📊 具體範例：貓/狗/鳥分類器
類別PrecisionRecallF1樣本數
貓0.900.800.85500
狗0.700.600.65500
鳥0.400.300.3410（很少！）
Macro F1
= (0.85 + 0.65 + 0.34) / 3
= 0.61

鳥（10個）和貓（500個）
權重一樣 → 鳥拉低整體
Micro F1
所有 TP/FP/FN 加總再算
貓狗各 500 個 → 影響大
鳥只 10 個 → 影響小
= 約 0.75（較高、較穩）
⚠️ 為什麼 Macro F1 波動性高？
鳥只有 10 個樣本，這次剛好多猜對 2 個，F1 從 0.34 跳到 0.55，整體 Macro F1 就被拉高很多。
但對整體模型來說，這 2 個鳥其實影響不大——少數樣本的隨機波動卻主導了整體指標。
Macro F1 = (F1_貓 + F1_狗 + F1_鳥) / 3　← 各類別同權

Micro F1：先加總 TP/FP/FN，再算 Precision、Recall、F1　← 樣本多的影響大
用 Macro F1 的情境
每個類別同等重要，不能讓少數類別被忽略
例：醫療診斷，罕見病只有 10 個案例也要認真對待
用 Micro F1 的情境（資料不平衡）
關心整體表現，小類別波動不應主導評估
例：電商分類，熱門商品幾萬個，冷門幾個
⚖️ Weighted F1 — 第三種選擇
介於 Macro 和 Micro 之間：按各類別樣本數加權後取平均，樣本多的類別對整體分數影響更大。
f1_weighted = Σ ( F1ₖ × nₖ ) / N
nₖ = 第 k 類的樣本數，N = 總樣本數
沿用上面的貓/狗/鳥範例（貓500、狗500、鳥10，共1010筆）：
= (0.85×500 + 0.65×500 + 0.34×10) / 1010 ≈ 0.75
鳥只有10筆，幾乎不影響結果 → 比 Macro（0.61）高很多，接近 Micro。
指標計算方式結果適合情境
Macro F1各類 F1 算術平均0.61每個類別同等重要（含少數類）
Micro F1加總 TP/FP/FN 再算≈0.75整體正確率，多數類主導
Weighted F1按樣本數加權平均≈0.75多分類不平衡資料的通用選擇
⚠️ 常見錯誤：多分類任務使用 scoring="f1"（不加後綴）→ 預設 average='binary'，直接報錯。
多分類應改用：scoring="f1_weighted"（不平衡）或 scoring="f1_macro"（少數類重要）或 scoring="accuracy"（資料平衡）
口訣：Macro「每類同權，小類別波動會拉動整體」／ Micro「樣本多的說了算，整體比較穩」
資料不平衡 → 優先 Weighted；每個類別同等重要（含少數類）→ 用 Macro；二分類 → 直接用 f1
AUC
AUC-ROC
Area Under the ROC Curve
🏫 國中生版本 — 先從這裡讀
模型對每個人輸出一個「有病的機率」（0～1）。問題是：機率多高才算「有病」？設 0.5？0.3？0.8？
ROC 曲線 = 把所有可能的閾值都試一遍，畫成一條曲線。

這條曲線的面積（AUC）就是分數：
 · AUC = 1.0：完美，所有閾值都分得很準
 · AUC = 0.5：和瞎猜一樣爛，無論怎麼設閾值都沒用

最簡單的理解：「隨機抓一個有病的人和一個沒病的人，模型給有病的人打更高分的機率」= AUC
所以 AUC 不管你設什麼閾值，直接測的是模型「分辨有病 vs 沒病的排序能力」。
🔬 為什麼「排在高分區」很重要？
假設模型對 5 人輸出的機率如下，兩個有病的都排在前面：
A（有病）→ 0.9
B（有病）→ 0.7
── 閾值設在這裡就能完美切開 ──
C（沒病）→ 0.6
D（沒病）→ 0.3
E（沒病）→ 0.1
不管閾值設 0.8、0.65 還是 0.5，有病的人都在閾值左邊，沒病的都在右邊——任何閾值都好用，這就是 AUC=1.0 的意思。
反例：如果分數混在一起
A（有病）→ 0.9
C（沒病）→ 0.7　← 沒病的跑進高分區了
B（有病）→ 0.5　← 有病的被擠到低分
D（沒病）→ 0.4
E（沒病）→ 0.1
閾值設 0.6 → 抓到 A，但也誤報 C
閾值設 0.4 → 抓到 A+B，但誤報 C+D
找不到一個閾值能同時高 Recall 又低誤報——AUC 因此下降。
AUC 的真正意義：不管你設什麼閾值，模型能不能讓兩群人清楚分開。
AUC 高 → 不管怎麼設閾值都好用
AUC 低 → 找不到一個閾值能同時準又不漏
① 先搞懂「閾值」
模型輸出的是機率，不是直接的類別。你要設一個閾值決定「多高才算有病」：
病人 A
機率 0.9
很可能有病
病人 B
機率 0.6
有點可能
病人 C
機率 0.3
不太可能
閾值 = 0.5 → A、B 判有病，C 判沒病
閾值 = 0.7 → 只有 A 判有病（更保守）
閾值 = 0.2 → 全部 判有病（超寬鬆）
→ 閾值不同，Precision 和 Recall 就不同。ROC 曲線把所有閾值都試一遍畫在同一張圖上。
② ROC 曲線怎麼畫
X 軸（FPR） = 沒病的人裡，被誤判有病的比例
Y 軸（TPR） = 有病的人裡，被正確找到的比例
閾值調低 → 右上角（高 TPR、高 FPR）
閾值調高 → 左下角（低 TPR、低 FPR）
AUC = 藍色曲線下面積
曲線越靠近左上角 → AUC 越大 → 模型越好
③ AUC 最直覺的解釋
隨機抽一個「真的有病」的人和一個「真的沒病」的人，
模型給有病的人打更高分的機率 = AUC

0.9

0.5
瞎猜

// 回歸任務指標
MAE
MAE（平均絕對誤差）
Mean Absolute Error
🏫 國中生版本
預測房價，平均每次差多少萬。差 10 萬和差 -10 萬都算 10 萬。最直覺，跟原始資料同單位。
MAE = (1/n) Σ |yᵢ − ŷᵢ|
對離群值不敏感（絕對值不會放大大誤差）。容易解釋：「平均誤差是 X 萬元」。
口訣：「平均差多少，取絕對值不管方向」
MSE
MSE（均方誤差）
Mean Squared Error
🏫 國中生版本
誤差先平方再平均。大誤差會被放大懲罰（差 10 萬 → 100 萬²；差 1 萬 → 1 萬²），讓模型更怕犯大錯。
MSE = (1/n) Σ (yᵢ − ŷᵢ)²
對離群值敏感，訓練時最常用（可微分）。單位是原始單位的平方，不夠直覺。
口訣：「差很多的懲罰更重，怕犯大錯用 MSE」
RMSE
RMSE（均方根誤差）
Root Mean Squared Error
🏫 國中生版本
MSE 開根號，讓單位回到原本的萬元，比 MSE 更好解釋，又保留對大誤差的懲罰。實務上最常報告的回歸指標。
RMSE = √MSE = √[(1/n) Σ (yᵢ − ŷᵢ)²]
RMSE ≥ MAE，差距越大代表越多離群值影響。
口訣：「MSE 開根號，單位變回來，大誤差還是重罰」
R²
R²（決定係數）
Coefficient of Determination
🏫 國中生版本
「我的模型解釋了多少比例的資料變化？」R² = 0.85 代表模型能解釋 85% 的變異，剩下 15% 是模型解釋不了的。
R² = 1 − (SS_res / SS_tot)
SS_res = Σ(y−ŷ)²，SS_tot = Σ(y−ȳ)²
R²≈1
完美
R²≈0.7
不錯
R²<0
比均值還差
口訣：「模型解釋了多少 %的資料變化」
R² 可以是負數：代表你的模型比直接猜平均值還爛
// 分群任務指標
Sil
Silhouette Score（輪廓係數）
群內緊密 vs 群間分離
🏫 國中生版本
對每個點問兩個問題：「我和同群的人有多近？我和最近的其他群有多遠？」分群越好，同群近、跨群遠，分數越高。
s = (b − a) / max(a, b)
a = 同群平均距離，b = 最近他群平均距離
範圍：−1 ~ 1，越接近 1 越好
s > 0.5 分群合理；s < 0 代表這個點可能分錯群了。
口訣：「同群要緊，跨群要遠，兩者差距越大越好」
DB
Davies-Bouldin Index
群內分散 vs 群間距離
🏫 國中生版本
對每群問：「我內部有多分散，和鄰群有多近？」越分散、越靠近其他群，分數越高（越差）。DB 越低越好。
DB = (1/k) Σ max[(sᵢ + sⱼ) / d(cᵢ,cⱼ)]
s = 群內平均距離，d = 群中心距離
越小越好（≠ Silhouette）
和 Silhouette 相反，DB 越低代表分群越好。
口訣：「DB 越低越好，跟 Silhouette 方向相反」
// 語言模型 / NLP 指標
BLEU
BLEU Score
Bilingual Evaluation Understudy — 機器翻譯評估
🏫 國中生版本
機器翻譯的結果和人工翻譯有幾個詞是一樣的？重疊越多，BLEU 越高。範圍 0～1。
BLEU = BP × exp(Σ wₙ log pₙ)
pₙ = n-gram 精確率，BP = 簡短懲罰
缺點：只看詞的重疊，忽略語意。「我愛你」和「你愛我」的 BLEU 可能一樣高。
口訣：「和標準答案重疊幾個詞，翻譯評估用」
RGE
ROUGE Score
Recall-Oriented Understudy for Gisting Evaluation
🏫 國中生版本
BLEU 看 Precision（我說的有幾個是對的），ROUGE 看 Recall（標準答案裡的詞，我說到幾個？），用於摘要評估。
ROUGE-N = 重疊的 n-gram 數 / 參考摘要的 n-gram 總數
ROUGE-L：最長公共子序列
ROUGE-1（單詞）、ROUGE-2（雙詞組）、ROUGE-L（最長序列）是最常報告的三種。
口訣：「標準答案的詞，我覆蓋到幾個？摘要評估用」
PPL
Perplexity（困惑度）
語言模型的預測不確定性
🏫 國中生版本
模型看到「今天天氣___」要猜下一個字，它覺得可能是多少個不同的字？Perplexity = 模型平均在幾個選項之間猶豫。越低越好。
PPL = exp(−(1/N) Σ log P(wᵢ|w₁...wᵢ₋₁))
越低 → 模型對下一個詞越有把握
PPL = 10
平均在10個詞間猶豫
PPL = 1000
模型很困惑
口訣：「模型平均在幾個詞之間猶豫，越低越確定」

📐 什麼是殘差？
殘差 = 真實值 − 預測值
預測房價 800 萬，實際 850 萬
殘差 = +50 萬 （低估）

預測 900 萬，實際 820 萬
殘差 = −80 萬 （高估）
🏫 國中生版本
你猜全班考試分數，「你猜的」和「實際考的」差多少就是殘差。把每個同學的差距畫在圖上，就是殘差圖。
✓ 理想：隨機散布
代表模型沒有系統性問題
🏫 猜錯的方式沒有規律，就像那天同學發揮失常，不是你的公式有問題。
⚠️ 弧形：非線性關係
模型用直線，但資料是曲線
🏫 用「身高×0.5=體重」，矮的人還行，但高的人完全不準，因為關係本來就不是直線。
修法：加入 x² 特徵或換非線性模型
⚠️ 漏斗形：異方差性
越往右誤差越大
🏫 用尺量鉛筆很準，但用同一把尺量操場誤差超大。
修法：對目標值取 log，或使用加權回歸
⚠️ 彎曲 + 極大殘差
高價區系統偏差 + 離群點
🏫 低分同學猜得準，但高分同學系統性猜低，還有一個人考超出預期很多。
診斷：C — 模型遺漏非線性關係
🔍 題目分析：為什麼是 C 不是 A、B、D？
A 過擬合 過擬合在訓練集殘差很小（死記答案），不會出現彎曲結構。問題是測試集表現差，不是殘差圖有規律。
B 欠擬合 欠擬合是「整體」高估或低估，殘差全部偏一個方向。題目是「高價區才出現彎曲」，是局部非線性，不是整體欠擬合。
C 非線性 ✓ 高價區出現彎曲 = 模型沒捕捉到非線性關係。加入 x² 特徵或換非線性模型可以修正。
D 隨機分佈 題目明確說有彎曲和極大殘差，根本不是隨機分佈。D 是干擾選項。

// 模型可解釋性工具（XAI — Explainable AI）
💡 為什麼需要可解釋性？
模型說「這個人貸款會違約」——為什麼？是因為收入低？年齡？負債？醫療、法律場景不能只看預測結果。
除錯時需要知道模型到底在看什麼特徵，而不只是「準確率 92%」。
🔍
SHAP
SHapley Additive exPlanations
基於賽局理論的「公平分配貢獻值」方法，計算每個特徵對某次預測結果的貢獻大小與方向。
SHAP 值 = 特徵 i 的邊際貢獻（考慮所有可能的特徵子集）
預測值 = 基準值 + Σ SHAP_i
正值 → 推高預測；負值 → 拉低預測
全局解釋：SHAP Summary Plot — 所有樣本的特徵重要性分布
局部解釋：SHAP Force Plot — 單一預測的每個特徵貢獻
支援：Tree SHAP（XGBoost 快速版）、Deep SHAP（神經網路）
🔍 國中生版本
5人團隊一起完成任務，要怎麼公平分獎金？SHAP 用賽局理論的「Shapley 值」計算每個特徵對這次預測貢獻了多少分（正或負）。「年齡+5分，收入-3分，負債-8分，所以預測違約」——每個特徵的責任都算清楚。
理論完備全局+局部結構化資料首選
🗺️
LIME
Local Interpretable Model-agnostic Explanations
在要解釋的樣本附近生成一批擾動樣本，用簡單線性模型擬合局部行為，以此解釋那次預測。
1. 在 x 附近隨機擾動 → 得到 {x', f(x')} 對
2. 按距離加權，訓練簡單線性模型 g
3. g 的係數 = 各特徵對此預測的重要程度
優點：Model-agnostic（任何黑盒模型都能用）、直覺易懂
缺點：擾動隨機性導致解釋不穩定、計算慢
支援：表格資料、影像（超像素遮蔽）、文字（詞語遮蔽）
🗺️ 國中生版本
複雜模型就像一個黑盒子，很難直接看透。LIME 的方法是：在這筆資料附近「微微改動各特徵」，看預測怎麼變，再用一條簡單直線來模擬這個局部行為。雖然全局複雜，但局部行為用直線就能解釋。
模型無關任何黑盒穩定性差
🌡️
Grad-CAM
Gradient-weighted Class Activation Mapping
用梯度資訊找出 CNN 最後一層卷積特徵對預測類別最重要的區域，生成熱力圖（Heatmap）疊加在原圖上。
1. 對目標類別計算梯度 → ∂y^c / ∂A^k（特徵圖 A^k）
2. 對空間維度做全局平均池化 → 權重 α^k_c
3. 熱力圖 = ReLU(Σ α^k_c × A^k)
用途：影像分類解釋、偵測模型有沒有「作弊」（看背景而非主體）
變體：Guided Grad-CAM（更細節）、Grad-CAM++（多目標物件更準）
限制：只適用於 CNN，不適用於全連接或 Transformer
🌡️ 國中生版本
CNN 說這張圖是「貓」，但它是在看貓臉還是在看沙發背景？Grad-CAM 算出每個像素區域對這個預測的梯度，把「重要的地方」畫成紅色熱力圖疊在原圖上。一眼看出模型是真的在看貓，還是在作弊。
影像解釋CNN 專用熱力圖視覺化
📊
Permutation Importance
特徵置換重要性
把某個特徵的值隨機打亂（破壞其資訊），看準確率下降多少，下降越多代表那個特徵越重要。
Importance(i) = baseline_score − score(打亂特徵 i 後)
重複多次取平均（降低隨機性）
📊 國中生版本
想知道哪個特徵最重要？把那一欄資料洗牌打亂，讓模型「看不到」那個特徵的真實資訊，再看預測準確率掉了多少。掉最多的特徵就是最重要的。簡單直觀，任何模型都可以用。
模型無關全局重要性易理解
📈
PDP / ICE Plot
Partial Dependence Plot / Individual Conditional Expectation
固定其他特徵，改變某一特徵的值，觀察預測結果如何隨之變化。PDP 看平均趨勢，ICE 看每個樣本的個別反應。
PDP: E[f(x_i, X_−i)]　對其他特徵取期望
ICE: f(x_i, x_−i^(j))　每個樣本各自一條線
📈 國中生版本
「年齡從 20 到 60，貸款違約的機率是怎麼變的？」PDP 把年齡從小到大變化，看預測的平均走勢，一條曲線就看出特徵和預測的關係是正比、反比還是非線性。ICE 則對每個人各畫一條線，看個別差異。
模型無關特徵關係視覺化
工具解釋範圍模型限制適合資料類型輸出形式
SHAP全局 + 局部無（Tree/Deep 版更快）表格、影像、文字貢獻值數字

□
IoU（交並比）
Intersection over Union
衡量預測框和真實框重疊程度的指標，決定一個預測是否算「抓到了」。
IoU = 交集面積 / 聯集面積　範圍：0～1
交集（黃）/ 聯集（兩框合併）
IoU 閾值：多高才算「抓到了」？
IoU = 0.9 — 高度重疊，✓ TP
IoU = 0.3 — 偏差大，✗ FP
IoU = 0 — 完全不重疊，✗ FP
IoU 閾值 = 0.5 → IoU ≥ 0.5 才算 TP（PASCAL VOC 標準）
IoU 閾值 = 0.75 → 更嚴格，框要更準確才算對
□ 國中生版本
用手電筒照一隻貓，照出來的光圈（預測框）和貓真正在的位置（真實框）重疊多少？重疊面積 ÷ 兩個框合起來的面積 = IoU。完全對準 = 1.0；差太遠 = 0。IoU 閾值就是「重疊多少才算找到了」的標準。

// 電腦視覺四大技術比較
💡 任務定義：對一張圖，你想知道什麼？
物件偵測：「哪裡有什麼？」畫框定位
語義分割：「每個像素是什麼類別？」
實例分割：「這個像素屬於第幾號物件？」
全景分割：「每個像素是誰？前景背景都要」
□
物件偵測（Object Detection）
定位 + 分類，輸出邊界框
在圖片上畫出邊界框（Bounding Box），標出每個物件的位置和類別。
輸出：[貓, x=50, y=30, w=100, h=80]
　　　[狗, x=200, y=40, w=90, h=75]
→ 知道「哪裡有貓」，但不知道每個像素
□ 國中生版本
在圖片上畫方框，告訴你「這裡有一隻貓、那裡有一隻狗」。只畫框，不填色。不知道框內哪些像素是貓、哪些是背景。
代表模型：YOLO、Faster R-CNN、SSD
定位+分類輸出框框不分像素
≡
語義分割（Semantic Segmentation）
每個像素分類，但不區分個體
對圖片中每個像素預測它屬於哪個類別，但同類別的不同個體不區分。
三隻貓 → 全部塗成同一個顏色（貓-綠）
→ 知道「哪些像素是貓」
→ 不知道是第幾隻貓
≡ 國中生版本
把圖片每個像素塗上顏色：「貓」塗綠色、「路」塗灰色、「天空」塗藍色。但三隻貓全部塗同一個綠色，分不出哪隻是哪隻。
代表模型：FCN、U-Net、DeepLab
像素分類不分個體醫療影像
∥
實例分割（Instance Segmentation）

// 基礎編碼方法
1️⃣
One-hot Encoding
One-hot Vector
將每個詞映射到一個向量，該詞位置為 1，其他位置為 0。
「貓」 → [0, 0, 1, 0, 0]
「狗」 → [0, 1, 0, 0, 0]
「鳥」 → [1, 0, 0, 0, 0]
特點：每個詞完全獨立，詞向量正交，無法表示詞之間的關係
問題：向量超高維、稀疏、詞量多時記憶體浪費
用途：分類任務的輸入、簡單快速的基準
1️⃣ 國中生版本
假設字典有 10 萬個詞，把每個詞做成一個 10 萬格的表格，只有那個詞的格子填「1」，其他全填「0」。每個詞是完全獨立的數字格，「貓」和「狗」之間沒有任何關係，浪費大量空間。現代已很少直接使用。
編碼方法分類已淘汰
🎒
Bag of Words（BoW）
Word Frequency Vector
統計句子中每個詞出現的次數，忽略詞序。
「貓喜歡狗，狗喜歡貓」
→ {貓: 2, 喜歡: 2, 狗: 2}
特點：簡單直觀，保留詞頻資訊，丟失詞序
缺點：無法區分「好評」和「評論」的順序差異
用途：垃圾郵件判斷、簡單分類
🎒 國中生版本
把一段文字倒進「袋子」裡，只記每個詞出現幾次，不管順序。「我喜歡狗」和「狗喜歡我」在 BoW 裡完全一樣（都是：我×1、喜歡×1、狗×1）。簡單但適合垃圾郵件等不需要語序的任務。

// 統計方法
📊
TF-IDF
Term Frequency - Inverse Document Frequency
賦予每個詞不同的權重：常見詞給低分，罕見且有區別性的詞給高分。
TF-IDF = TF(t,d) × IDF(t)
TF = 詞在文件出現次數 / 文件總詞數
IDF = log(文件總數 / 包含該詞的文件數)
優點：快速、直觀、計算量小，對文本分類有效
缺點：詞義完全無關、語序被忽視、高維稀疏
用途：資訊檢索、文本搜尋、關鍵詞提取
📊 國中生版本
BoW 的升級版：「的、是、了」這種常見詞給低分（它們到處都有，沒有區分力），「人工智慧」這種稀有且特定的詞給高分。搜尋引擎用這個找你要的文件——包含罕見關鍵詞的文件排最前面。
統計方法搜尋分類經典方法
🔗
N-grams
Sequence of N Words
將文本分成連續 N 個詞的短片段，保留部分語序資訊。
文本：「我 很 喜歡 機器 學習」
Unigram(1-gram): 我、很、喜歡、機器、學習
Bigram(2-gram): 我很、很喜歡、喜歡機器、機器學習
Trigram(3-gram): 我很喜歡、很喜歡機器、喜歡機器學習
特點：比 BoW 保留更多上下文、比完整序列更簡潔
權衡詳解：
• N 越大 → 稀疏性高：可能組合數呈指數增長（N=5 時 1000^5 組合），但實際文本中大多組合很少出現，導致特徵向量充滿 0
• N 越小 → 失去資訊：N=1 完全丟失詞序，「狗咬人」和「人咬狗」無法區分
• 實用建議：N=2 (bigram) 是最佳平衡點
用途：拼寫檢查、語言模型、文本分類
🔗 國中生版本
把句子切成連續幾個詞的小片段。N=2 就切成「每兩個詞一組」：「機器學習」比「機器」+「學習」更有意義。N 大 = 更完整語意，但可能組合太多、沒資料；N 小 = 資料多，但語意片段。通常 N=2（bigram）最實用。
⚠️ N-gram 的致命限制：只有短暫記憶
N-gram 預測下一個詞，只靠前 N-1 個詞（馬可夫假設）。片段上合理，但整體不連貫：
「上週客戶反映購買的 A 產品有問題，
雖然已經安排維修，但客戶說希望能 ___」

Trigram 只看前 2 個詞：「客戶說希望能」→「退款？延保？...」
完全不知道「A 產品」「已維修」這些資訊（相隔 15 個詞以上）
N-gram 做得到
局部片段語言合理
（「客戶說」後面接「希望」是對的）
N-gram 做不到
記住 15 個詞以前說了什麼
→ 整體語意不連貫
解法：RNN（有記憶機制）或 Transformer（Self-Attention 直接看全句）

// 主題建模（Topic Modeling）— LDA vs NMF
💡 主題建模在做什麼？
給一堆文章，自動找出「這批文章在討論哪些主題」，並計算每篇文章各主題的比重。不需要任何標籤，是非監督式學習。例如：5 萬篇新聞 → 自動發現「體育」「政治」「財經」等主題。
≥0
NMF（非負矩陣分解）
Non-negative Matrix Factorization
把「文件×詞彙」矩陣分解為兩個非負矩陣的乘積，直接得到每篇文章的主題比重與每個主題的關鍵詞。
V (文件×詞彙) ≈ W (文件×主題) × H (主題×詞彙)
三個矩陣的所有元素都必須 ≥ 0
目標：最小化 ‖V − WH‖²（重建誤差）
W — 文件×主題矩陣
文章 1：體育 0.72、政治 0.18、財經 0.10
文章 2：體育 0.05、政治 0.85、財經 0.10
每篇文章在各主題的比重（全為正數）
H — 主題×詞彙矩陣
主題1（體育）：球、比賽、球員…
主題2（政治）：選舉、政策、議員…
每個主題由哪些詞彙組成（全為正數）
⚠️ 核心限制：輸入矩陣所有元素必須 ≥ 0
NMF 的更新規則建立在「全部非負」的假設上。若輸入有負值（如 TF-IDF 浮點誤差），分解結果無意義或演算法發散。
✗ 有負值不能直接用
TF-IDF 平滑後出現極小負數 → 需先處理
✓ 解決方案
V = np.maximum(0, tfidf)
或改用原始詞頻矩陣（BoW）
≥0 國中生版本
把一張「5萬篇文章 × 10萬個詞」的大表格，分解成兩個小表格相乘：一個記「每篇文章談了多少比例的體育/政治/財經」，另一個記「每個主題最常用哪些詞」。因為比例和詞頻都不可能是負數，所以三個矩陣全部元素必須 ≥ 0——這就是「非負」的由來，也是最大的限制。
為何比 PCA 更適合主題建模：PCA 的主成分含負值（「體育主題佔 −0.3」無意義）；NMF 全正數，直接對應「主題比重」，可解釋性強

// 詞嵌入（Word Embeddings）
⃗v
Word2Vec
Skip-gram / CBOW
用淺層神經網路學習低維詞向量，使得**語義相似的詞在向量空間裡距離近**。
Skip-gram: 輸入中心詞 → 預測周圍詞（1 輸入，多輸出）
CBOW (Continuous Bag Of Words): 輸入周圍詞 → 預測中心詞（多輸入，1 輸出）
結果：「國王」- 「男人」+ 「女人」≈「皇后」
記憶技巧：
• Skip-gram：「跳過」中心詞，給你中心詞，學習預測周圍詞
• CBOW：周圍詞的「袋子」，給你周圍詞，學習預測被包圍的中心詞
• 快速判斷：要預測「周圍詞」→ Skip-gram；要預測「中心詞」→ CBOW
優點：快速訓練、詞向量有意義的語義、維度低（通常 300）
缺點：一詞多義無法區分、OOV 詞無表示、靜態嵌入
訓練：skip-gram 快，CBOW 更穩定；負採樣加速
⃗v 國中生版本
把每個詞變成一串數字（向量），語義相近的詞向量也相近。「國王」-「男人」+「女人」≈「皇后」。Skip-gram 給中心詞猜周圍詞；CBOW 給周圍詞猜中心詞。背法：Skip = 只知道自己，猜旁邊的人；CBOW = 周圍都知道，猜中間那個。

嵌入通用經典快速
🌐
GloVe
Global Vectors for Word Representation
結合**全局統計**（詞共現矩陣）和**局部學習**，同時利用全局語料庫統計和局部上下文。
目標函數考慮詞對共現的全局模式
本質：加權最小平方迴歸
差異：Word2Vec 掃描局部窗口學習 vs GloVe 先算全語料共現矩陣再優化
核心差異：
• Word2Vec = 近視眼：只看 5-10 詞的滑動窗口，逐句學習
• GloVe = 鷹眼：先統計整個語料庫詞對共現 1000 萬次，再用統計直接優化向量
• 結果：GloVe 向量加法關係更清楚（king-man+woman≈queen）
優點：向量品質好、訓練快（直接矩陣分解而非逐句神經網路）、向量加法關係明確
缺點：同樣無法處理一詞多義、OOV 詞問題
何時用：**大數據集**（共現統計才有價值），需要向量加法關係明確的場景
🌐 國中生版本
Word2Vec 一次只看一個句子的小窗口。GloVe 先統計整個語料庫裡每兩個詞同時出現幾次，再用這張「全局統計表」一次算出所有詞向量。像「鷹眼」看全局，比「近視眼」逐句學習更穩定，向量加法關係更準確。
嵌入通用向量好
⚡
FastText
Subword Embeddings
改進 Word2Vec，把詞分解成**字符 n-gram**，能處理 OOV 詞和形態變化。
「跑步」拆成: <跑, 跑步, 步>（3-gram）
詞向量 = 其所有 n-gram 向量之和
OOV (Out Of Vocabulary)：訓練詞彙表中沒有出現的詞
關鍵創新：
• Word2Vec = 死記硬背：整詞記憶，遇到新詞「黑松露」就無法表示
• FastText = 看偏旁部首：拆成字符片段「黑」「松」「露」「黑松」「松露」，即使新詞也能表示（因為片段見過）
• 結果：拼寫錯誤「跑歩」也能表示（大部分 n-gram 與「跑步」相同）
優點：能表示 OOV 詞、處理字符變化（拼寫錯誤）、多語言友善（形態豐富語言）
缺點：向量維度更大（多個 n-gram 相加）、訓練更慢、一詞多義仍無法區分
何時用：**中文、形態豐富語言、需要容錯、詞彙表有稀有詞**
⚡ 國中生版本
Word2Vec 遇到沒看過的詞就「不認識」。FastText 把每個詞拆成小片段（「機器學習」→「機器」「器學」「學習」），用片段的向量加總代表整個詞。新詞「量子運算」雖然沒看過，但「量子」和「運算」見過，所以能猜出意思。

// 預訓練神經模型
🌀
ELMo
Embeddings from Language Models
用雙向 LSTM 在無標籤大量文本上做**語言模型預訓練**，提取深層表示作為嵌入。
通過語言模型任務學習 → 預測下一詞
使用多層 LSTM 的內部狀態作為詞表示
革新：第一次成功的深層預訓練模型，**動態詞向量**（同詞不同語境不同向量）
優點：處理一詞多義、下游任務性能大幅提升
缺點：計算慢、模型大、被 BERT 取代
🌀 國中生版本
Word2Vec 裡「蘋果」永遠是同一個向量，不管是「吃蘋果」還是「蘋果公司」。ELMo 用雙向 LSTM 讀整個句子，同一個詞在不同句子裡給出不同的向量（動態嵌入）。是第一個成功解決「一詞多義」問題的模型。
預訓練NLP 通用里程碑
🅱️
BERT
Bidirectional Encoder Representations from Transformers
用 Transformer 做雙向預訓練，通過**遮蔽語言模型**和**下句預測**任務學習深層文本表示。
MLM: 隨機遮蔽 15% 的詞 → 預測它們
NSP: 判斷兩句是否相鄰
訓練 768-1024 維向量
優點：**轉移學習標準**，微調即可解決各類下游任務，性能遠超 Word2Vec
機制：Transformer Encoder 雙向注意力，上下文充分
應用：分類、QA、命名實體、語義相似度……幾乎所有 NLP 任務
🅱️ 國中生版本
訓練時隨機遮住句子裡 15% 的詞，要模型猜出來（像填空題）。同時雙向讀懂上下文（左邊+右邊一起參考）。訓練完之後，拿去做各種 NLP 任務只需要小幅微調，準確率大幅超越之前所有方法，是現代 NLP 的分水嶺。
📝 MLM（遮蔽語言模型）深入說明
原句：「今天 天氣 很 好 我 想 出去 玩」
遮蔽後：「今天 天氣 很 [MASK] 我 想 出去 [MASK]」
模型要猜：[MASK] → 「好」　[MASK] → 「玩」
猜出填空詞，就必須真正理解上下文語意——這讓同一個詞在不同語境下有不同的向量（動態嵌入）：
「我 買 了 一 顆 [MASK]」
→ 蘋果 / 西瓜 / 球
「[MASK] 公司 發 布 新 產品」
→ 蘋果 / 谷歌 / 微軟

比例處理方式原因
80%換成 [MASK]主要訓練任務

// Transformer · BERT · GPT · Seq2Seq — 關係統整
🏛️ 原點：原始 Transformer（2017，Attention is All You Need）
Encoder
Multi-head Self-Attention
（雙向，看全句）
→
Decoder
Masked Self-Attention（單向）
+ Cross-Attention（看 Encoder）
用途：翻譯（英文→法文）。針對特定任務從零訓練，沒有預訓練知識。
🅱️ BERT = Encoder 部分 + 大規模預訓練
把原始 Transformer 的 Encoder 拿出來，在海量文本上做 MLM 填空預訓練。
特點：雙向，看左又看右
用途：理解 — 分類、NER、QA
單獨使用 ≠ Seq2Seq（沒有 Decoder）
🚀 GPT = Decoder 部分 + 大規模預訓練
把原始 Transformer 的 Decoder 拿出來，在海量文本上做自迴歸語言模型預訓練。
特點：單向，只看左邊（自迴歸）
用途：生成 — 寫文章、對話、程式
單獨使用 ≠ Seq2Seq（沒有 Encoder）
🔁 Seq2Seq = Encoder + Decoder 同時存在
Seq2Seq 是一種架構概念，不是特定模型。凡是「輸入一段序列、輸出另一段長度可不同的序列」都算。
原始 RNN Seq2Seq（2014）
LSTM Encoder + LSTM Decoder，Google 翻譯的前身
T5（2020）
Transformer Encoder + Decoder，把所有 NLP 任務統一成文字生成
BART（2019）
BERT 風格 Encoder + GPT 風格 Decoder，你說的那個組合！
典型應用
翻譯、自動摘要、對話系統、語音辨識
✅ 你的理解完全正確：BERT（Encoder）+ GPT（Decoder）= Encoder + Decoder = Seq2Seq 架構。BART 就是這樣做的，而且效果非常好。
模型架構來源方向用途單獨 = Seq2Seq？
原始 TransformerEncoder + Decoder雙向+單向翻譯（從零訓練）✓ 是
BERTEncoder only雙向理解任務✗ 否（沒有 Decoder）
GPTDecoder only單向生成任務✗ 否（沒有 Encoder）
BERT + GPT（BART）Encoder + Decoder雙向+單向摘要、翻譯✓ 是
T5Encoder + Decoder雙向+單向所有 NLP 任務✓ 是
💡 一句話記： BERT = 只讀不寫（理解）；GPT = 只寫不讀（生成）；Seq2Seq = 先讀懂再重新寫（翻譯/摘要）。
BERT 和 GPT 是原始 Transformer Encoder/Decoder 各自加上預訓練的升級版，合在一起就是 Seq2Seq。
// Attention Collapse — 注意力分布過於平均
⊘
Attention Collapse
注意力崩潰 — 無法聚焦關鍵詞
✓ 正常注意力
「貓 坐 在 沙發 上」
貓：0.05　坐：0.05
在：0.05　沙發：0.80　上：0.05
→ 聚焦關鍵詞，語意清晰
✗ Attention Collapse
「貓 坐 在 沙發 上」
貓：0.20　坐：0.20
在：0.20　沙發：0.20　上：0.20
→ 每個詞都差不多，語意模糊
⚙️ 為什麼會發生？— 縮放常數的影響
Attention 公式：softmax( QKᵀ / √d )
點積太小時
e^x 差距微小 → Softmax 輸出趨於均勻 → Collapse
點積夠大時
e^x 差距大 → Softmax 集中在高分詞 → 正常聚焦
🔧 改善策略比較
策略做法效果
✓ 稀疏化約束 Top-K 注意力 / Entmax / Sparse Transformer 只保留少數高權重位置，強迫聚焦
✗ 提高縮放常數 讓除數更大 → 點積更小 加劇 Collapse，方向錯誤
✗ Softmax 前加雜訊 加入高斯隨機雜訊 讓注意力更隨機，無針對性
✗ ReLU 取代 Softmax 負值歸零，正值保留 破壞機率分布性質，輸出無法歸一
⊘ 國中生版本
想像你在看一段文字，注意力正常時會「盯著關鍵字看」。但 Attention Collapse 就像你眼睛散焦了，看每個字都差不多用力，結果什麼都沒真正看進去。

解法（稀疏化）就是強迫模型：「最多只能認真看 K 個詞，其他的全部忽略」——讓注意力像聚光燈，而不是散光。
Transformer 診斷注意力機制稀疏化解法

⚠️ 檢索階段最關鍵挑戰：語意相似 ≠ 意圖相關
向量搜尋找的是「餘弦相似度最高」的文件，但語意相近不代表能回答問題：
用戶問：「蘋果公司的最新股價是多少？」

向量搜尋找到（相似度高）：
✗ 「蘋果的營養價值與種類介紹」
✗ 「水果市場的價格走勢分析」

→ 語意上都有「蘋果」「價格」，但完全答不了問題
→ LLM 拿到這些文件後，反而生成錯誤答案（Hallucination 加劇）
RAG 最難的不是「搜不到」，而是「搜到了但搜錯了」。
Reranker
候選文件用更精準的模型重新排序，淘汰語意偏移的結果
Hybrid Search
向量搜尋 + BM25 關鍵字搜尋結合，彌補純向量的語意漂移
Query Expansion
把用戶問題改寫成多種形式再搜尋，增加召回率
意圖分類
先判斷問題類型，再選對應搜尋策略，提升精準度
🔎 國中生版本
RAG 就是：「先去圖書館查資料，再把查到的資料給 AI，讓 AI 根據資料回答問題」。

最大的挑戰是：圖書館員（向量搜尋）找書的方式是靠「書名聽起來像」（語意相似），但「蘋果公司股價」和「蘋果水果介紹」聽起來都有「蘋果」，找到了但找錯書，AI 就算看再多也回答不了問題。
挑戰類型發生在哪個階段嚴重程度

文件超過上下文視窗生成階段次要 — 截斷或摘要可緩解
嵌入計算成本高索引建立階段工程問題 — 有成熟工具解決
搜尋函式庫選擇工程實作次要 — Faiss/ScaNN 都可以
