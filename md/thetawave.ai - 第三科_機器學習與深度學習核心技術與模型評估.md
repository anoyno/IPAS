## 📊 統計方法與模型評估技巧

### 交叉驗證（Cross-Validation）在模型泛化能力檢驗中的應用

- **定義**：交叉驗證是一種評估機器學習模型在未觀察資料上表現的統計方法。
- **用途**：用於檢驗模型對新資料的適應能力與泛化效果。
- **適用場景**：當企業想評估銷售預測模型在不同月份新資料上的穩定性時，交叉驗證是最佳選擇。

> **重點**：交叉驗證透過將資料分割成多個子集，反覆訓練與驗證模型，以降低評估結果的偏差。

### 交叉驗證方法比較

| 方法名稱 | 適用條件 | 優點 | 注意事項 |
| --- | --- | --- | --- |
| 5-Fold 交叉驗證 | 資料樣本量中等 | 計算成本適中，驗證結果穩定 | 不一定保證類別分佈均勻 |
| 留一法交叉驗證（Leave-One-Out） | 資料樣本量非常小 | 最大化資料利用率，適合小樣本 | 計算成本高，可能過度波動 |
| 分層留一法交叉驗證（Stratified Leave-One-Out） | 類別不平衡，且樣本數有限 | 保持各類別比例，兼顧資料利用率 | 適合極端不平衡資料 |
| 隨機交叉驗證 | 資料量大，不強調類別比例 | 實現簡單，計算快速 | 可能導致類別比例失衡 |

## 🛠️ 正則化與防止過度擬合策略

### L1 正則化（Lasso）的主要效果

- **功能**：產生**稀疏模型（Sparse Model）**，即部分參數權重收斂為零，達到特徵選擇效果。
- **應用**：避免模型過度複雜，提升泛化能力。

### 防止過擬合的策略比較

| 策略 | 作用說明 | 是否降低模型複雜度 |
| --- | --- | --- |
| L1 / L2 正則化 | 懲罰過大權重，限制模型複雜度 | 是 |
| Dropout 技術 | 隨機丟棄神經元，減少過度依賴 | 是 |
| 早期停止（Early Stopping） | 訓練過程中監控驗證損失，適時停止 | 是 |
| 擴增輸入特徵變數 | 增加模型表達能力，反而可能加重過擬合 | 否 |

## 📌 DBSCAN 群集分析核心概念

| 類型 | 定義 |
| --- | --- |
| 核心點（Core Point） | 鄰域內的樣本數達到設定閾值，能形成密度連通區域 |
| 邊界點（Border Point） | 鄰域內樣本數不足以形成核心點，但屬於某核心點鄰域 |
| 雜訊點（Noise Point） | 鄰域內樣本數不足以形成核心點，且不屬於任何核心點鄰域，也未與其他群集形成密度可達關係（Density Reachability） |

> 若資料點不符合核心點、邊界點條件，且無密度可達關係，則被視為**雜訊點**。

## 🧠 深度學習模型關鍵機制與架構

### 卷積神經網路（CNN）第一層卷積層的主要功能

- **自動提取輸入影像中的局部特徵**，如邊緣、角點等基礎圖像元素。
- 透過**區域感知（Local Receptive Field）**與**參數共享（Parameter Sharing）**機制，達到降低參數數量與運算複雜度的效果。

### CNN 相較於全連接神經網路（FCNN）的優勢

- 主要因為 CNN 利用局部感知與參數共享，降低模型參數量，提升訓練與推論效率。
- CNN 可直接從原始影像中自動學習特徵，避免人工特徵設計。

### 激活函數（Activation Function）在深度學習中的重要性

- **ReLU（Rectified Linear Unit）**激活函數引入非線性，提高模型表達能力，解決線性激活函數導致訓練停滯的問題。
- Sigmoid 函數將輸出壓縮至 $\lbrack 0,1\rbrack$ 範圍，但容易造成梯度消失。

## 🎯 模型評估指標與偏差

| 指標 | 定義與解釋 |
| --- | --- |
| 精確率（Precision） | 正確預測為正例的比例 |
| 召回率（Recall） | 真正正例中被正確預測的比例 |
| F1 分數（F1 Score） | 精確率與召回率的調和平均數，計算公式如下： |
|  | $F1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$ |

- 精確率 0.8，召回率 0.6，F1 分數約為 0.686。

## 📉 主成分分析（PCA）與降維

### PCA 特徵值與解釋變異量

- 特徵值 $\lambda_i$ 代表第 $i$ 個主成分的變異量。
- 保留主成分的做法是選擇能解釋至少 80% 總變異量的組合。

#### 範例數據解讀

| 主成分 | 特徵值 | 解釋變異量比例（%） | 累積解釋變異量（%） | 是否可保留 |
| --- | --- | --- | --- | --- |
| 第一主成分 | 6.0 | 60 | 60 | 是 |
| 第二主成分 | 3.0 | 30 | 90 | 是 |
| 第三主成分 | 1.0 | 10 | 100 | 否 |

> 依此，保留前兩個主成分即可達到至少 80% 變異量解釋，適合降維。

## 🧮 演算法時間複雜度理解

| 複雜度符號 | 說明 | 代表意義 |
| --- | --- | --- |
| $O(n)$ | 線性時間複雜度 | 執行時間與資料量成正比 |
| $O(n^2)$ | 平方時間複雜度 | 執行時間與資料量平方成正比 |
| $O(1)$ | 常數時間複雜度 | 執行時間固定不變 |
| $O(\log n)$ | 對數時間複雜度 | 執行時間與資料量呈對數成長關係 |

### 範例說明

- 計算所有客戶兩兩間相似度，演算法時間複雜度為 $O(n^2)$，因為每個客戶要與其他 $n-1$ 位客戶比較。

## 🎲 Monte Carlo 方法與條件機率計算

- 事件 A：擲出偶數
- 事件 B：擲出大於3的數字

**條件機率**$P(A|B)$的計算公式為：

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

- 正確程式碼為：`A_and_B.sum() / B.sum()`（選項 D）

| 標準化屬於特徵選擇(Feature Selection) | 錯誤，標準化是特徵縮放(Feature Scaling) | 錯誤 |

### 激活函數數學式

- ReLU（修正線性單元）激活函數的數學式：

$$f(x) = \max(0, x)$$

- Sigmoid 激活函數通常用於二元分類（binary classification），非多類別分類

### 損失曲線繪製說明

- 繪製訓練與驗證損失曲線時，線條風格可用符號表示：

| 符號 | 代表意義 |
| --- | --- |
| `"b-"` | 藍色實線（訓練損失） |
| `"b--"` | 藍色虛線（驗證損失） |
| `"r-"` | 紅色實線 |
| `"r--"` | 紅色虛線 |

- 驗證損失下降幅度較訓練損失更明顯，可能暗示模型過擬合
